# UI와 main 통합 검수

UI 작업 보존: `04166d1` / 팀원 main: `50ef612` / 병합: `767acc8`.

현재 작업 브랜치는 `ui/academy-hud`이며 로컬 main도 origin/main까지 전진했다. 병합 충돌 없음. UI PNG와 meta, 승인한 화면 및 전투 조작부를 유지한다. 팀원의 수련 점수·저장·기술 문구 변경은 그대로 반영했다.

EditMode 1216/1216 통과. 전체 PlayMode 비교에서 원본은 560개 중 445 통과·114 실패·1 제외, 병합본은 561개 중 446 통과·동일 114 실패·1 제외다. 추가 실패는 없다. 원본의 실패 목록과 메시지는 validation.json에 남긴다. 검사 결과의 전체 통과를 의미하지 않는다.

화면 8종은 실제 Unity HUD 빌더로 1920×1080 출력했다. 검수용 씬과 메모리 캠페인을 사용해 실제 저장은 수정하지 않았다.

팀원 변경을 다음에 반영할 때 현재 브랜치에서 `git fetch origin`, `git merge origin/main`을 사용한다. `main`으로 체크아웃하면 팀원의 원본 개발 상태이며 UI 작업은 ui/academy-hud에 있다.

최종 집중 PlayMode는 62개 중 61 통과, 1 실패다. 기록 버튼 클릭 테스트의 실패는 원본에서도 같은 메시지로 발생한다. 아이콘과 글자의 겹침은 4px 간격 조정으로 해결하고 내용 영역·문구·그림·입력 검사를 유지했다. 전체 원본의 기존 실패를 이번 병합에서 고쳤다는 의미가 아니다.
