# 서막 1 임무 전투 대사 (상대: 허수아비)
# 쓰는 법은 Docs/Barks.md에 있습니다. 대사를 적기 전에는 전투 중에 아무것도 뜨지 않습니다.
# 쓸 상황 줄 앞의 #을 지우고, 그 아래에 대사를 한 줄에 하나씩 적으세요. 여러 줄이면 그 상황마다 하나를 골라 말합니다.
# 말하는 쪽: 상황 뒤에 아무것도 없으면 상대(enemy), player를 붙이면 엘리사입니다. 예) @on enemy-hurt player
# ( )로 감싼 대사는 속마음 색으로 보입니다. 한 줄은 40자까지, 20자 안쪽이 읽기 좋습니다.
#
# @on start            # 첫 편성 턴이 시작될 때
# @on enemy-broken     # 허수아비의 저항이 붕괴될 때
# @on player-broken    # 엘리사의 저항이 붕괴될 때
# @on enemy-hurt       # 허수아비가 한 번에 큰 피해를 입을 때 (잠시 뒤 다시 나올 수 있음)
# @on player-hurt      # 엘리사가 한 번에 큰 피해를 입을 때 (잠시 뒤 다시 나올 수 있음)
# @on enemy-low        # 허수아비의 체력이 처음 30% 이하로 떨어질 때
# @on player-low       # 엘리사의 체력이 처음 30% 이하로 떨어질 때
