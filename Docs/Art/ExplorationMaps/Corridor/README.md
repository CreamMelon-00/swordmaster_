# 학교 복도 탐색 맵 리소스

기존 전투용 노란 석조 복도를 가로 3화면 정도의 **유한한 탐색 공간**으로 확장한 그림 리소스다. 우측 끝은 창이 반복되는 벽이 아니라 가스등과 월넛 양문을 둔 독립 출구 벽면이다. 마지막 기존 기둥 뒤에서 석재와 목재 패널 높이가 자연스럽게 이어지며, 얕은 실내 문턱으로 마감한다. 현재 폴더에는 맵 그림만 들어 있다. 필드 이동·문 상호작용은 게임 구현에서 연결한다.

원화는 기존 `Docs/Art/SchoolCorridor/Applied/corridor-{far,near,interior}.png`의 팔레트와 배치를 잇는다. `build_corridor.ps1`이 `build_corridor.py`와 `build_master.lua`를 차례로 실행해 모두 다시 만든다. 번들 Python/Pillow와 `C:\Users\User\Desktop\Aseprite\Aseprite.exe`가 필요하다.

## 공간·문 위치

- 원화 크기: **4096×724px**. 1024×181 논리 픽셀을 최근접 4배로 확대한 4×4 도트 격자다.
- 런타임 크기: **4096×916px**. 원화가 런타임 y=160~883에 정확하게 들어가며, 세 레이어가 같은 기준점을 쓴다.
- 기존 벽/바닥 경계: 원화 **y≈432px**. 넓은 벨트 바닥과 기존 인물 발높이 구도를 유지한다.
- 왼쪽 끝: 닫힌 석조 벽체. 오른쪽 끝: 별도 종단 벽체와 출구.
- 오른쪽 월넛 양문: 원화 **x≈3600~3840px**, 중심 **x≈3720px**. 둘러싼 석재 아치 **x≈3552~3888px**. 얕은 문턱은 **y≈436~459px**에서 대리석 바닥으로 이어진다.
- 마지막 창과 출구 사이에는 본래의 석재 기둥 하나와 가스등을 둔 조용한 벽면이 있다. 출구는 숲 그림의 건물 출입구와 외형·크기·문턱을 정확히 맞추지 않은 독립 장면이다.
- 원본의 석재 픽셀군과 목재 패널 높이를 유지한다. 출구 앞의 바닥은 없는 창의 강한 투사광을 제거하고, 원본 대리석 결과 줄눈을 연결된 낮은 대비 픽셀군으로 정리했다.

세 레이어 모두 불투명 색상 최대 64개, 알파 0/255, 정확한 4×4 픽셀 격자다. 런타임 여백은 기존 복도 적용판과 같은 규칙으로 마지막 행을 반복해 만든다. 바깥 원경은 불투명하고 수목은 별도 투명 레이어이며, 창·벽·바닥은 상단 실내 레이어에 있다.

## 2026-10-16 창밖 풍경 접합 수정

창밖 원경과 수목에 실내 창문 배치를 늘리는 자르기 규칙을 함께 적용해, 원본 끝 x=2172px에서 서로 다른 풍경을 붙인 수직 경계가 생겼다. 원경의 x=3052px 이후는 투명하게 남아 있었다. 두 레이어는 카메라에 따라 실내와 다르게 움직이므로 이 경계가 창문 가운데에 보였다.

`build_corridor.py`는 창밖 두 레이어를 원본 끝에서 반사 연장해 전체 4096px을 채운다. 경계의 양쪽 열이 같은 픽셀을 사용하고, 원본 앞 2172px의 픽셀과 팔레트를 보존한다. `verify_scenery_joins.py`는 경계의 RGBA 일치, 전체 원경의 불투명도, 4배 도트 격자, 편집용/게임용 파일의 일치를 검사한다. 수정 전에는 원경 경계의 492행 불일치로 실패했고 수정 후 두 레이어 모두 0행으로 통과했다.

Unity 렌더 비교에서 바닥의 햇빛·대리석 무늬도 같은 x=2172px에서 끊기는 것을 추가 발견했다. 생략된 원본 바닥의 앞 24열을 겹쳐 넣고, 색 차이가 작은 불규칙 경계로 연결했다. 원화 x=2088~2171, y=436~723 안의 888논리 픽셀만 바뀌며, 새 색·흐림·반투명 혼합·반사 없이 빛무늬의 사선 방향을 유지한다. 창문·문·벽·목재 패널은 픽셀 그대로다. 검증 스크립트는 바닥 경계도 원래 이웃한 두 도트 열과 일치하는지 확인한다.

숲의 탐색 배경은 이미 동일한 반사 연장을 사용한다. 전투 숲·복도는 실제 배치 코드가 이웃 타일을 교대로 반전해 같은 끝 픽셀끼리 연결하므로 추가 수정하지 않았다. 로비·타이틀·브리핑 배경은 단일 이미지로 표시된다. 이번 수정은 탐색 복도 PNG 3종과 그 편집 원본·미리보기에 한정한다. 조사표와 Unity 전후 렌더 기록은 `LoopRepair20261016/`에 보관한다.
