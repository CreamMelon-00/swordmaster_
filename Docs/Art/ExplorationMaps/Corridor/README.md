# 학교 복도 탐색 맵 리소스

기존 전투용 노란 석조 복도를 가로 3화면 정도의 **유한한 탐색 공간**으로 확장한 그림 리소스다. 우측 끝은 창이 반복되는 벽이 아니라 별도 종단 벽체이며, 월넛 양문으로 숲 쪽 출구를 나타낸다. 현재 폴더에는 맵 그림만 들어 있다. 필드 이동·문 상호작용은 게임 구현에서 연결한다.

## 파일

| 위치 | 내용 |
| --- | --- |
| `Authored/corridor-far.png` | 창밖 먼 하늘과 교정 |
| `Authored/corridor-near.png` | 창밖 앞쪽 나무 |
| `Authored/corridor-interior.png` | 석조 벽, 창틀, 가스등, 월넛 문, 바닥 |
| `Runtime/corridor-*.png` | 게임용 위 160px·아래 32px 여백 포함 3레이어 |
| `corridor-master.aseprite` | 동일한 3레이어를 담은 편집 가능한 Aseprite 원본 |
| `Preview/corridor-composite.png` | 4096×724 합성 확인용 |
| `Preview/corridor-logical-1x.png` | 실제 도트 구조를 볼 수 있는 1024×181 판 |
| `qa-report.txt` | 규격 자동 검증 결과 |

원화는 기존 `Docs/Art/SchoolCorridor/Applied/corridor-{far,near,interior}.png`의 팔레트와 배치를 잇는다. `build_corridor.ps1`이 `build_corridor.py`와 `build_master.lua`를 차례로 실행해 모두 다시 만든다. 번들 Python/Pillow와 `C:\Users\User\Desktop\Aseprite\Aseprite.exe`가 필요하다.

## 공간·문 위치

- 원화 크기: **4096×724px**. 1024×181 논리 픽셀을 최근접 4배로 확대한 4×4 도트 격자다.
- 런타임 크기: **4096×916px**. 원화가 런타임 y=160~883에 정확하게 들어가며, 세 레이어가 같은 기준점을 쓴다.
- 기존 벽/바닥 경계: 원화 **y≈432px**. 넓은 벨트 바닥과 기존 인물 발높이 구도를 유지한다.
- 왼쪽 끝: 닫힌 석조 벽체. 오른쪽 끝: 별도 종단 벽체와 출구.
- 오른쪽 월넛 양문: 원화 **x≈3600~3840px**, 중심 **x≈3720px**. 둘러싼 석재 아치 **x≈3552~3888px**. 문턱은 y≈432~499px에서 바닥으로 이어진다.
- 창은 종단 벽체 이전에 끝나므로 문이 창 바로 옆에 붙어 보이지 않는다. 숲 맵의 학교 외벽 문과 월넛·노란 석회석 재질을 맞춘다.

세 레이어 모두 불투명 색상 최대 64개, 알파 0/255, 정확한 4×4 픽셀 격자다. 런타임 여백은 기존 복도 적용판과 같은 규칙으로 마지막 행을 반복해 만든다. 바깥 원경과 수목은 각각 독립 투명 레이어이고, 창·벽·바닥은 상단 실내 레이어에 있다.
