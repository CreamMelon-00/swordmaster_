# 숲 탐색 필드 리소스

새벽빛의 노란 숲길을 가로 약 3화면 길이로 만든 유한한 벨트 스크롤 배경이다. 왼쪽에는 가스등이 달린 낮은 출입기둥과 나무 사이로 이어지는 작은 길이 있고, 그 너머 멀리 19세기 석조 학교가 보인다. 복도 출입문과 숲 입구는 각 장면의 구도에 맞춰 독립적으로 표현한다.

## 레이어와 배치

각 레이어는 **4096×724px**이며, **1024×181 논리 픽셀을 정확하게 4배 확대한** 도트 격자다. 합성 순서는 `far-mist` → `far-trees` → `belt-mid` → `near`다. 투명도는 0 또는 255이며 레이어별 불투명 색은 최대 64개다.

왼쪽 입구는 첫 1360px 구간 안에서 기존 숲에 불규칙한 경계로 합쳐진다. 작은 학교와 입구기둥은 `belt-mid`에 넣어 현재 카메라의 시차 이동에도 위치가 유지되게 했다. 학교는 크기, 나무의 가림, 회청색 지붕과 공기색으로 거리를 표현한다. 중앙과 오른쪽의 기존 먼 숲 레이어, 넓은 모래길과 전경 수풀의 색·도트는 유지한다. 학교의 실물 문짝을 가까이 배치하지 않는다.

학교 쪽으로 이어지는 입구길은 대략 **x=260~570px** 구간에 있다. 현재 필드 상호작용의 기준 **x=352px, y=488px**은 이 길의 앞쪽에 해당한다. 오른쪽 철책은 **x≈3740~4096px**에 있다. 좌표의 원점은 원화의 왼쪽 위다.

Unity 권장 가져오기 설정은 **128 PPU, Point, Clamp, Full Rect, 밉맵 없음, 압축 없음, 최대 텍스처 4096**이다. 네 레이어의 기준점과 크기는 같아야 한다.

## 다시 내보내기

`build_forest.ps1`은 승인된 입구 그림을 원화 격자로 정리하고 기존 숲의 팔레트와 이음새에 맞춘다. 기존 구간의 색을 다시 양자화하지 않으며, x=1360px 이후의 레이어는 Base와 픽셀 완전히 동일한지 검사한다. 기존 복도 이미지에 대한 의존성은 없다.

PNG 제작 뒤 Aseprite에 네 레이어를 넣어 마스터를 저장하고 다시 내보낸 결과가 Source와 완전히 동일한지 확인한다. 실행에는 번들 Python/Pillow와 `C:\Users\User\Desktop\Aseprite\Aseprite.exe`가 필요하다.

새 입구의 생성 그림은 구도와 창작 픽셀을 제공한다. 패킹 과정은 격자 축소, 팔레트 정리, 기존 숲과의 경계 선택만 수행한다. 새 건물이나 문을 도형 코드로 그리지 않는다.
