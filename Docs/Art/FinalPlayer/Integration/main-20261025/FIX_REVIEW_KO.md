대상은 main에 반영된 `e5e64e4`(아트 통합 `f6fea1a`, 포함된 main `773dec6`)이다. 점검 도중 별도 긴장 기능의 Runtime·Presentation·CSV 변경이 진행되어 해당 작업은 보존하고, 병합 당시 입력의 고정 사본에 이번 수정만 적용해 검증했다.

## 확인하고 수정한 문제

- `ArtValidationRunner`가 모든 Test Runner 실행의 완료 콜백을 받아 일반 EditMode·PlayMode 결과까지 아트 검증의 `playmode.xml`에 저장하던 문제를 수정했다. 아트 실행 소유권과 진행 상태를 `SessionState`에 보관해 도메인 재로드를 처리하며, 소유한 결과만 한 번 저장한다. 다른 실행 중에는 요청을 보존하고, 실행 예외·오류·중복 완료와 저장 실패 이후의 잘못된 재저장을 막는다.
- PlayMode 검사 21개 파일의 확인 가능한 준비 오류와 낡은 기준을 정리했다. 상대 카드 조회에서 안내용 형제를 제외하고 실제 카드만 찾으며, 대전 전용 ID 62도 전체 기술 정의에서 조회한다. 버튼 검사는 실제 세션을 먼저 표시한다.
- 현재 쿠페 감소 10에 대해 남은 저항 9로 붕괴·상한을 검사하고, 저항 15에서는 붕괴하지 않는 조건도 별도 순수 시나리오로 확인했다. 베기·숙련·호흡·돌파·추격·순환의 기대값은 승인된 현재 시트에 맞췄으며 추격은 3타 미충족에서 4타 충족으로 검증한다. 전체 카드 검사는 고정된 기술 개수 대신 고유 ID와 대전·시험 기술의 포함 여부를 확인하고 모든 정의의 양쪽 표시·숙련 표시·잘림을 계속 검사한다.
- 숲의 위치 유지 검사는 좌표를 이동하기 전에 실제 밀림 종료를 기다리며, 밀림·재접촉 검사는 실제로 밀림을 발생시키는 타격 속성을 사용한다. FinalPlayer의 접촉 프레임·가드·PPU를 반영하고, 구형 변형 난수 검사는 구형 경로를 명시적으로 선택한 뒤 설정을 복구한다. 기존 접촉·이동 오차·상태 비변이 검사는 유지했다.
