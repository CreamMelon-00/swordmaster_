# 로비 오두막 배경 제작 기록

아침·낮·저녁·밤 네 장은 같은 임시 거처를 같은 실내 시점에서 보여 준다. 승인된 네 장은 `Assets/Game/Resources/LobbyRoom/{morning,day,evening,night}.png`에 복사해 타이틀과 로비 배경으로 사용한다. 이전 `room.png`는 보존하지만 현재 타이틀·로비의 선택 후보에는 포함하지 않는다.

공유받은 마을 이미지는 돌건물·슬레이트 지붕·노란 차양·녹색 언덕·먼 첨탑의 **분위기와 요소**를 참고했다. 거리의 카메라 구도는 따르지 않았다. 방 안에서 본 두꺼운 창틀과 열린 덧문, 바로 앞의 지붕, 그 뒤의 길과 언덕이 하나의 원근으로 이어지도록 구성했다.

## 이미지 생성 프롬프트 요약

내장 ImageGen 도구를 사용했다. 기본 그림은 새로 생성했고, 나머지 시간대는 기본 그림의 조명 편집으로 제작했다.

- **공통 구도:** 16:9 도트 게임 로비. 임시 목조 오두막 안에 서 있는 1인칭 시점. 같은 원근을 따르는 기둥·서까래·마루와 오른쪽 벽의 깊은 여닫이창. 창밖에는 가까운 돌집과 지붕, 비스듬히 물러나는 돌길, 노란 차양, 먼 언덕의 첨탑 일부만 자연스럽게 보인다. 간이 침상, 여행 궤짝, 작은 책상, 유리와 황동으로 된 가스등 두 개와 소량의 구리 배관. 인물·문구·UI·화면처럼 보이는 정면 파노라마 제외. 일정한 픽셀 덩어리와 절제된 색감.
- **아침:** 옅은 금빛 일출, 먼 언덕의 푸른 안개, 실내의 서늘한 그림자와 긴 햇빛, 약하게 켜진 가스등.
- **낮:** 선명한 푸른 하늘과 높은 태양. 창 가까이 짧게 드는 햇빛, 밝고 고른 실내 빛, 희미한 가스등.
- **저녁:** 낮은 구리빛·장밋빛 하늘, 청보라색 마을 그림자, 점차 강해지는 따뜻한 가스등.
- **밤:** 남색 하늘과 희미한 달빛, 몇 개의 마을 창 불빛. 실내의 주광원은 두 가스등이며 바닥에 낮의 주황색 햇빛 무늬가 남지 않는다.

네 이미지의 장소·가구·카메라 위치는 동일하며 시간에 따른 조명만 달라진다. 게임 시작 시 네 시간대 중 하나를 무작위로 한 번 고르고 타이틀과 로비가 같은 그림을 사용한다. 로비 탭 변경이나 전투 후 복귀 시에는 선택을 유지한다.

## 저장 형식

`morning`, `day`, `evening`, `night` 각각 편집용 960×540 Aseprite(RGB)와 미리보기용 1920×1080 PNG가 있다. PNG는 Aseprite에서 최근접 2배로 내보내 일정한 2×2 픽셀 블록을 유지한다. 작은 가스등·지붕 디테일이 깨지지 않도록 색 수를 강제로 줄이거나 디더링하지 않았다.

게임 리소스 PNG는 이 미리보기 PNG와 동일하다. Unity에서는 각각 Single Sprite, Point 필터, Clamp, sRGB, 압축 없음, Mipmap 없음, 최대 크기 4096으로 가져온다.
