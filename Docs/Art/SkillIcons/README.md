기존 `skill-role-atlas.png` 15개는 그대로 둔다. 새 그림은 별도 Sprite로 로드한다. 탐색은 방어 계열의 올리브색 테두리와 눈, 작은 청록색 ACT 회복 표식이다. 몰아치기는 참격 계열의 구리색 마름모 테두리와 검, 연속 베기 궤적이다. 무기와 문양은 기술의 판정이나 수치를 대신하지 않는다.

이아의 수훈 이후 적 전용 기술 3개는 예외적으로 **황금색 효과**를 공통 포인트로 쓴다. 라우다레는 구리색 참격 테두리 안에서 검이 황금 저항 고리를 깨는 연속 베기, 베네디체레는 올리브색 방어 테두리 안의 금장 투구와 다시 이어지는 고리, 프레디카레는 구리색 참격 테두리 안의 단일 내려베기와 거의 소진된 붉은 체력 고리다. 같은 금빛을 공유하지만 실루엣은 각각 파열·투구·일격으로 구분한다. 숫자나 종교 문양을 새로 넣지 않았다.

내장 ImageGen으로 기존 아틀라스를 스타일 참고 이미지로 사용해 각 아이콘을 별도로 생성했다. 생성본을 Aseprite에서 25%로 축소해 313×313 투명 PNG와 편집 가능한 `.aseprite` 원본으로 저장했다. `Explore-56.png`와 `Barrage-56.png`는 실제 버튼 크기 판독용 미리보기다. Unity 임포트는 Point / Clamp / 무압축 / Mipmap 없음 / 중앙 pivot을 사용한다.

수훈 3종은 내장 ImageGen에서 `role17.png`(라우다레·프레디카레)와 `role16.png`(베네디체레)를 각각 편집 대상으로 사용했다. 출력 1254×1254를 Aseprite에서 313×313으로 줄인 뒤 PNG와 `.aseprite`로 저장했다. 각 이름의 `-48.png`·`-56.png`는 실제 적 기술 큐와 작은 버튼 크기 확인용이며, `EnemyEmpowermentIcons-preview.png`는 세 아이콘을 함께 보는 미리보기다. 원본 그림 16·17과 기존 아틀라스는 수정하지 않았다.
