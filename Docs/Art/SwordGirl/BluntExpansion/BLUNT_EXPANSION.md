# 타격 3종 / 전체 공격 9종

타격 2종을 추가해 참격·관통·타격이 각각 3종입니다. 타격 2번은 검자루를 아래에서 짧게 올려치는 동작, 3번은 검자루를 들어 아래로 내리찍는 동작입니다. 날이나 검끝을 들이대는 공격과 구분되도록 둥근 금색 폼멜이 먼저 나가도록 구성했습니다.

| 모션 | Aseprite 태그 | 프레임 | Unity 리소스 |
| --- | --- | --- | --- |
| 기존 타격 | Blunt | 33–44 | blunt |
| 짧은 올려치기 | Blunt2 | 97–108 | blunt-2 |
| 검자루 내려찍기 | Blunt3 | 109–120 | blunt-3 |

`SwordGirl_AllAttacks3.aseprite`는 120프레임·14태그의 통합 편집본입니다. 기존 96프레임은 픽셀 비교로 동일함을 검사합니다. 새 동작은 각각 12프레임, 256×224 투명 PNG입니다. 첫 프레임과 마지막 프레임은 공통 준비 자세이며, 5번 프레임을 기존 접촉 시점에 맞춥니다. 원본은 1.26초, 게임에서는 기존 1/6초 공격 주기로 재생합니다. GIF는 원본 속도입니다.

세 공격 타입 모두 타격마다 3종 중 하나를 무작위로 선택하고 해당 타격 중에는 선택을 유지합니다. 히트스톱·시간 되감기에서 다시 뽑지 않으며, 새 타격·새 슬롯에서 다시 뽑습니다. 같은 모션이 연달아 나올 수 있습니다. 공격 종류를 바꾸면 이전 슬롯의 선택 기록을 초기화합니다. 게임 피해 계산과 외형용 난수는 분리됩니다.

내장 ImageGen으로 두 원화 시트를 생성한 뒤 실제 Aseprite Lua API에서 포즈 분리, 기존 팔레트 적용, 머리·접지점 정렬, 프레임 조립과 PNG/GIF 내보내기를 수행했습니다. 머리 그림 자체의 확대·축소는 하지 않으며, 3번의 의도적인 무릎 굽힘과 낮아지는 자세는 유지합니다. 타격은 검이 머리 뒤로 가려지는 구간이 있으므로 보이는 검날 조각을 전체 검으로 잘못 재구성하지 않고 원화의 가림 관계를 보존합니다. 회수 구간에는 기존 검을 세운 자세를 넣습니다.

제작 지시는 `PROMPTS.md`, 조립·정렬 코드는 `build_blunts.lua`, `cleanup_motion.lua`입니다. Unity는 40 PPU, Point 필터·무압축, 피벗 (101,22)을 사용합니다. 게임 카메라 캡처와 자동 PlayMode 검증은 사용자 에디터를 유지한 채 동일 리소스의 별도 프로젝트 복사본에서 수행합니다. 자동 검증은 동작 연결과 판정 시점을 확인하며 미적 완성도 자체를 보증하지 않습니다.

2026-09-28 Unity 6000.5.9f1 검증: `playmode-results.xml`에서 88/88 Passed, 0 Failed, 43.38초. 타격 3종 게임 카메라 렌더는 `Captures/unity-blunt.png`, `unity-blunt-2.png`, `unity-blunt-3.png`입니다. 실제 프로젝트와 검증 복사본의 변경 코드·테스트·PNG·메타·타이밍 56개 파일이 SHA-256으로 일치합니다. Aseprite 조립 시 기존 96프레임 동일, 전체 120프레임·14태그, 새 24개 PNG 잘림 없음도 확인했습니다.
