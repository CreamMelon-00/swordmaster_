# 관통 3종

기존 관통을 유지하고 상단 짧은 찌르기와 몸을 실은 깊은 찌르기를 추가합니다. 베기 3종, 타격 1종, 가드·피격 각 2종을 유지합니다.

| 모션 | Aseprite 태그 | 프레임 | Unity 리소스 |
| --- | --- | --- | --- |
| 기존 관통 | Pierce | 21–32 | pierce |
| 상단 짧은 찌르기 | Pierce2 | 73–84 | pierce-2 |
| 깊은 찌르기 | Pierce3 | 85–96 | pierce-3 |

`SwordGirl_Slash3_Pierce3.aseprite`는 96프레임·12태그의 편집본입니다. 새 동작은 각각 12프레임, 256×224 투명 PNG로 내보냅니다. 기존 72프레임은 픽셀 비교로 보존을 검사합니다. 모든 공격의 접촉은 5번 프레임이며 기존 게임 피해 판정 시점에 맞춥니다. 원본 길이 1.26초와 게임 기본 공격 길이 1/6초는 기존 설정을 유지합니다. GIF는 동작 확인용 원본 속도입니다.

타격마다 3종 중 하나를 선택하고 같은 타격 중에는 선택을 유지합니다. 히트스톱·시간 되감기에서 다시 뽑지 않으며, 새 타격과 새 스킬 슬롯에서 다시 뽑습니다. 같은 종류가 연속으로 나올 수 있습니다. 전투 판정과 외형 난수는 분리됩니다.

내장 ImageGen으로 2개 원화 시트를 만들고 실제 Aseprite Lua API에서 프레임 분리, 팔레트 통일, 머리 위치·발 기준 정렬, 강체 검날 길이 및 각도 정리, 애니메이션 조립과 PNG/GIF 출력을 수행합니다. `PROMPTS.md`에 원문 제작 지시를 보관합니다. 머리 그림 자체를 프레임마다 확대·축소하지 않습니다. 2번은 머리 높이를 유지하며 짧게 뻗고, 3번은 앞무릎을 굽히고 발 간격을 넓혀 의도적으로 몸을 낮춥니다. 검날 길이는 73px로 유지하며 찌르기·회수 구간은 수평입니다.

Unity는 Point 필터, 무압축, 40 PPU, 피벗 (101,22)을 사용합니다. 제작 스크립트는 `build_pierces.lua`, `cleanup_motion.lua`입니다. 테스트는 열린 사용자 에디터 대신 동일 리소스의 별도 복사본에서 실행합니다. 자동 검사는 리소스·접촉 시점·타격별 랜덤 유지·공격 종류 전환·기존 전투 회귀를 확인하며, 미적 완성도를 자동으로 확정하지 않습니다.

2026-09-28 Unity 6000.5.9f1 검증: `playmode-results.xml`에서 84/84 Passed, 0 Failed, 43.99초. 관통 3종의 게임 카메라 렌더는 `Captures/unity-pierce.png`, `unity-pierce-2.png`, `unity-pierce-3.png`입니다. 실제 프로젝트와 검증 복사본의 변경 코드·테스트·PNG·메타·타이밍 55개 파일의 SHA-256이 일치합니다. Aseprite 조립 단계에서 기존 72프레임 동일, 96프레임·12태그, 새 24개 PNG 잘림 없음도 확인했습니다.
