# 베기 3종 확장

베기 1종을 유지하고 올려 베기와 수평 베기를 추가했습니다. 이번 단계의 관통·타격은 기존 각 1종입니다. 막기·피격 각 2종과 이벤트별 무작위 선택도 유지합니다.

| 모션 | 태그 | 전체 원본 프레임 | 리소스 |
| --- | --- | --- | --- |
| 기존 내려 베기 | Slash | 9–20 | slash/frame-01 … 12 |
| 올려 베기 | Slash2 | 49–60 | slash-2/frame-01 … 12 |
| 수평 베기 | Slash3 | 61–72 | slash-3/frame-01 … 12 |

편집 원본은 `SwordGirl_Slash3.aseprite`입니다. 기존 48프레임은 픽셀 비교로 동일함을 확인했으며, 전체 72프레임·10태그입니다. PNG는 `Assets/Game/Resources/SwordGirl/Animations` 아래에 있습니다. 공통 256×224, 40 PPU, 피벗 (101,22), Point 필터·무압축과 기존 팔레트를 사용합니다.

## 끊겨 보이는 동작 보완

첫 구성은 주요 자세를 여러 프레임 동안 반복해서 중간 연결이 부족했습니다. 추가 베기 2종은 준비·후속·회수 중간 그림을 보강해 각 12프레임 중 11장을 서로 다른 그림으로 구성했습니다. 첫 프레임과 마지막 프레임은 동일한 기본 자세로 연결됩니다.

## 2026-09-28 크기와 궤적 수정

사용자가 지적한 2·3번 베기의 크기 변화와 어색한 검 회수를 수정했습니다. 서로 다른 원화 시트에 동일한 축소율만 적용하던 방식에 머리·접지점 기준 보정을 추가했습니다. 머리 부분은 확대·축소하지 않고 위치를 정렬하며, 그 아래 몸통·다리의 높이와 발 간격을 별도로 맞춥니다. 2번의 머리 기준점은 73~95px에서 72~79px로 줄이고, 3번은 73~74px로 유지합니다. 발바닥은 y=202, 양발 외곽 간격은 약 89px입니다. 의도적인 작은 무게중심 이동은 남깁니다.

2번은 몸 보정과 독립된 강체 검날을 다시 그려 길이 73px를 유지하며, 후반 각도를 -60도에서 기본 준비 자세의 약 -58도로 연결합니다. 기존 검날 잔여 픽셀도 제거합니다. 3번은 팔꿈치를 굽혀 몸 가까이에서 회전하는 새 원화로 바꾸고, 몸 앞을 지나는 단축 원근 자세와 후속 동작을 넣었습니다. 검의 원근에 따른 길이 변화와 캐릭터 전체 크기 변화는 구분합니다. 정리 코드는 `cleanup_motion.lua`입니다.

GIF는 효과 레이어를 제외한 캐릭터만 보여줍니다. Aseprite 편집본에는 선택적으로 켤 수 있는 효과 레이어가 유지됩니다. 타이밍 JSON 생성도 순수 Lua 테이블로 다시 구성해 반복 실행 시 기존 클립이 null로 바뀌던 내보내기 오류를 수정했습니다.

미리보기 GIF는 원본의 1.26초 길이입니다. 게임에서는 기존 공격 규칙에 맞춰 기본 속도 기준 1/6초에 재생합니다. 따라서 미리보기보다 훨씬 빠르며, 자동 테스트 통과가 애니메이션의 미적 완성도를 보증하는 것은 아닙니다. 게임 공격 속도와 피해 판정 시점은 이번 단계에서 변경하지 않았습니다.

## 선택과 판정

베기 타격마다 3종 중 하나를 무작위로 선택합니다. 별도의 외형용 난수열을 사용합니다. 타격 번호별로 선택 결과를 저장해, 히트스톱이나 시간 보정으로 같은 타격을 다시 샘플링해도 동작이 바뀌지 않습니다. 같은 모션이 연달아 나올 수 있습니다. 준비 자세의 첫 샘플부터 모션이 정해지므로 베기 도중 다른 모션으로 바뀌지 않습니다.

세 모션 모두 다섯 번째 프레임을 기존 접촉 시점에 맞춥니다. 기존 콤보 간격, 피해·저항력 계산, 가드·피격, 스텝·잔상은 유지합니다.

## 제작과 검증

기본 제공 ImageGen으로 키 포즈와 중간 포즈 원화를 생성한 뒤 실제 Aseprite Lua API로 분리, 팔레트 통일, 접지점 정렬, 프레임 조립, 별도 효과 레이어와 PNG/GIF 출력을 진행했습니다. 제작 지시는 `SLASH_PROMPTS.md`, 조립 스크립트는 `build_slashes.lua`입니다.

Unity 자동 PlayMode 검증은 사용자가 열어둔 에디터를 유지한 채 별도 복사본에서 실행합니다. 베기 3종의 리소스·접촉 시점, 타격마다 선택·선택 유지, 시간 되감기, 가드·피격과 전투 템포 회귀를 검사하며 실제 게임 카메라로 세 접촉 자세를 렌더합니다.

2026-09-28 수정본 검증: `playmode-revision.xml`에서 80/80 Passed, 0 Failed(44.03초). 실제 프로젝트와 검증 복사본의 새 PNG·메타·타이밍 49개 파일이 SHA-256으로 동일합니다. `Captures/unity-slash.png`, `unity-slash-2.png`, `unity-slash-3.png`는 해당 실행에서 얻은 게임 카메라 렌더입니다. Aseprite 조립 시 기존 48프레임 픽셀 동일, 72프레임·10태그, 새 프레임 캔버스 잘림 없음도 검사했습니다. 연속 동작의 주관적 자연스러움은 자동 테스트만으로 확정하지 않습니다.
