# 전투 결과

## 결과 확인 후 다음 행동

일반 전투는 마지막 슬롯의 모든 타격/애니메이션과 턴 마무리까지 끝낸 뒤 전장 위 결과 창을 연다. 바로 방 로비로 이동하지 않는다. 승리/패배/무승부, 스테이지 이름, 진행 턴, 양쪽 남은 HP, 획득/보유 재화, 첫 클리어/재클리어와 새 개방 단계를 표시한다.

보상과 해금은 `CampaignRun.TryCompleteBattle`에서 한 번만 확정한다. `BattleResult`는 그 값을 보관하는 불변 스냅샷이며 창을 다시 표시하거나 닫는 행위로 재화를 지급하지 않는다. 결과 창이 열린 동안 큐 예약·거래·편성·일반 출정은 차단된다.

- **로비로**: 결과를 닫고 방으로 돌아간다. Enter/Escape도 동일하다.
- **재도전**: 현재 스테이지를 다시 시작한다. 기술 소유/강화/편성/재화는 유지하고 체력·저항·큐·기록·위치를 초기화한다.
- **다음 스테이지**: 승리했고 다음 단계가 개방되어 있을 때만 표시한다. 마지막 8단계에는 표시하지 않는다.

일반 전투 도중 Escape는 기존처럼 무보상 포기 후 로비로 돌아간다. 최종 클리어/반복 클리어 보상 규칙은 기존과 같다. 결과가 확정되면 진행을 자동 저장한다(`SaveSystem.md`).

## 서막 임무의 결과

서막 임무(`PrologueMissions.md`)도 같은 결과 창을 쓴다. 제목은 `임무 완료`/`임무 실패`, 부제는 `서막 · 임무 NN · 이름`이다. 보상 재화·첫 클리어·스테이지 해금은 없다(`BattleResult.IsMission`이면 생성자가 거부한다).

- **브리핑으로**: 실패했을 때만 표시한다. 아직 깨지 않은 임무의 브리핑으로 돌아간다. 서막을 이미 마쳤다면 **로비로**가 된다. Enter/Escape도 동일하다.
- **재도전**: 시작 대사 없이 같은 임무를 처음부터 다시 한다. 이미 깬 임무를 다시 해도 진행은 바뀌지 않는다.
- **다음 임무**: 승리했을 때만 표시한다. 다음 임무의 브리핑을 연다(Enter/Escape도 동일). 마지막 임무이거나 서막을 이미 마쳤다면 **여정 계속**이 되고 로비를 연다. 승리 화면에는 브리핑으로 버튼을 두지 않는다. 다음 임무와 같은 곳으로 가기 때문이다.

승리한 임무는 종료 대사를 먼저 재생하고 그 뒤에 결과 창을 연다.

## 소유와 연결

- Runtime `BattleResult`: 확정된 결과 표시용 스냅샷.
- Presentation `DuelPrototypeController`: 기존 입력/수동 전투 시계/마무리 경로에 결과를 연결한다. 결과·로비·브리핑에서는 전투 시계를 멈춘다.
- Presentation `BattleResultHud`: 기존 스타일의 결과 모달과 버튼.

자동 부트스트랩이 구성하므로 Inspector나 씬 수동 연결은 없다. 실제 검증 범위와 한계는 `Validation.md`를 따른다.
