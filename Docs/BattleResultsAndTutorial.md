# 전투 결과와 직접 조작하는 튜토리얼

## 결과 확인 후 다음 행동

일반 전투는 마지막 슬롯의 모든 타격/애니메이션과 턴 마무리까지 끝낸 뒤 전장 위 결과 창을 연다. 바로 방 로비로 이동하지 않는다. 승리/패배/무승부, 스테이지 이름, 진행 턴, 양쪽 남은 HP, 획득/보유 재화, 첫 클리어/재클리어와 새 개방 단계를 표시한다.

보상과 해금은 `CampaignRun.TryCompleteBattle`에서 한 번만 확정한다. `BattleResult`는 그 값을 보관하는 불변 스냅샷이며 창을 다시 표시하거나 닫는 행위로 재화를 지급하지 않는다. 결과 창이 열린 동안 큐 예약·거래·편성·일반 출정은 차단된다.

- **로비로**: 결과를 닫고 방으로 돌아간다. Enter/Escape도 동일하다.
- **재도전**: 현재 스테이지를 다시 시작한다. 기술 소유/강화/편성/재화는 유지하고 체력·저항·큐·기록·위치를 초기화한다.
- **다음 스테이지**: 승리했고 다음 단계가 개방되어 있을 때만 표시한다. 마지막 8단계에는 표시하지 않는다.

일반 전투 도중 Escape는 기존처럼 무보상 포기 후 로비로 돌아간다. 최종 클리어/반복 클리어 보상 규칙은 기존과 같고 디스크 저장을 추가하지 않았다.

## 기초 연습 입구

방 로비 홈의 **기초 연습 · 튜토리얼**, 스테이지 탭의 **기초 연습 · 보상 없는 튜토리얼**로 입장한다. 첫 실행을 강제로 연습에 가두지 않고 언제든 다시 연습할 수 있다. 별도 씬이나 패키지 없이 기존 숲길·캐릭터·검 아이콘·애니메이션·VFX를 재사용한 전용 연습 전투다.

연습은 `TutorialStage.CreateDuel`이 별도로 생성한다. 일반 여정의 재화·소유·강화·편성·선택 단계·해금/클리어를 변경하지 않는다. 편성 제한시간과 자동 확정은 전체 연습에서 사용하지 않는다. 안내 중에도 실제 전장이 보이며 필요한 카드/큐/ACT/확정 위치를 강조한다.

| 순서 | 학습 | 실제 진행 조건 |
|---|---|---|
| 소개 | 선택은 즉시 공격이 아니라 예약이다 | 시작/Enter |
| 공격 예약 | ACT 1 소비, 머리 위 첫 큐 | Q 짧게 누르기 또는 베기 카드 클릭 |
| 후속 예약 | 같은 순번 충돌, 다음 슬롯 지원 | W 또는 찌르기 카드 클릭 |
| 방어 예약 | 사용한 기술은 열 뒤로 회전한다 | Q의 다음 카드인 막기 예약 |
| 상대 확인 | 적 큐와 기술 설명 | Tab 또는 적 큐 확인 버튼 |
| 확정 | 예약한 순서대로 실제 교전한다 | Space/Enter 또는 확정 버튼 |
| 교전 관찰 | 공격 대결은 저항, 방어/빈 상대는 체력 | 실제 첫 턴 타격과 마무리 완료 |
| 회복 확인 | 잔여 이월·기본 3·기술 회복 | 다음 턴 ACT 6 확인 후 계속/Enter |
| 자유 전투 | Q/W/E로 직접 조합하고 승리한다 | 제한시간 없이 실제 결투 완료 |

초기 안내는 지정한 예약만 허용해 설명이 잘못된 큐를 따라가지 않는다. 클릭/입력이 실제로 예약에 성공한 경우에만 다음 단계로 넘어간다. 단순히 다음 버튼을 누르는 것으로 예약·확정·교전 단계를 건너뛰지 않는다. 자유 전투부터는 모든 기술열을 사용할 수 있다. 긴 Q/W/E 홀드는 기존 기술 설명, 짧게 누르고 떼기는 예약이다.

연습의 Q열은 베기/막기, W열은 찌르기/흘리기, E열은 부수기/강력한 부수기/쳐내기로 구성한다. 기존 기본 기술의 수치/효과를 바꾸지 않는다. 상대는 HP32/저항12, 위력1~2 검 공격을 사용하며 첫 턴3행동/이후1행동이다. 세 번째 적 기술이 타격 속성이어서 안내한 막기의 실제 회복 조건을 만족한다. Q→W→Q는 시작 ACT3을 소비하고 다음 턴에는 기본3+베기1+막기2로 ACT6이 된다.

연습 결과 창의 **다시 연습**은 처음부터 안내를 재시작한다. **로비로** 또는 안내의 **연습 종료**, 전투 중 Escape는 여정 변경 없이 방으로 돌아간다. 연습 클리어 보상이나 일반 스테이지 해금은 없다. 승리 뒤 상점/편성/첫 스테이지로 이어지는 길을 설명하되 거래를 강제하거나 재화를 만들어내지 않는다.

## 소유와 연결

- Runtime `TutorialProgress`: 성공한 조작과 실제 턴 전환에 맞춘 안내 단계, 허용 동작, 학습 문구.
- Runtime `TutorialStage`: 여정과 독립된 연습 전투 구성.
- Runtime `BattleResult`: 확정된 결과 표시용 스냅샷.
- Presentation `DuelPrototypeController`: 기존 입력/수동 전투 시계/마무리 경로에 결과·연습 연결. 결과 또는 로비에서 전투 시계 정지.
- Presentation `BattleResultHud`/`TutorialCoachHud`: 기존 스타일의 결과 모달/비차단 안내와 버튼. `LegacyCombatHud`는 강조와 무제한 연습 표시만 추가한다.

자동 부트스트랩이 구성하므로 Inspector나 씬 수동 연결은 없다. 실제 검증 범위와 한계는 `Validation.md`를 따른다.
