# 붕괴 표시

2026-09-30 도입. 저항이 깨진 상태(받는 체력 피해 ×2)가 화면에 보이지 않던 것을 보이게 했습니다. 전투 규칙은 바꾸지 않았습니다.

## 규칙 (변경 없음)

- 저항이 0이 되면 붕괴입니다. 붕괴 중에는 받는 체력 피해가 2배가 됩니다.
- 붕괴 순간 타격의 넘친 피해는 2배가 되지 않습니다. 압박 추가 피해도 2배가 되지 않습니다.
- 3턴에 깨지면 3턴의 남은 타격과 4턴 내내 붕괴 상태입니다. 5턴이 시작될 때 저항이 최대치로 회복됩니다. 원본 게임 규칙을 옮긴 것입니다.
- 계획 단계에서 붕괴 중인 캐릭터는 항상 다음 턴 시작에 회복됩니다. 그래서 남은 턴 수는 따로 표시하지 않습니다.

## 화면

- **붕괴 이펙트 (캐릭터):** 붕괴 중인 캐릭터에 붉은 윤곽이 천천히 맥동하고, 발밑 그림자 위에 금 간 고리가 생깁니다.
  - 붕괴가 풀리면 0.15초에 걸쳐 사라집니다.
  - 전투 시계를 따릅니다. 타격 정지 중에는 멈추고, 슬로모션 중에는 느려집니다.
  - 캐릭터 스프라이트의 색은 건드리지 않습니다. 타격 번쩍임과 겹치지 않습니다.
  - 대상은 상태 그대로입니다(`LegacyFighterState.IsResistanceBroken`). 투지로 저항을 조금 회복하면 붕괴가 풀린 것이므로 이펙트도 사라집니다.
- **붕괴 순간 문구:** 저항이 깨지는 순간 그 캐릭터의 허리 높이에서 "붕괴 ×2"가 떠오릅니다. 높이는 화면 픽셀이 아니라 캐릭터 기준 거리(`LegacyCombatHud.StateCalloutWorldOffset`, 1.3 아래)라서 붕괴 클로즈업처럼 카메라가 확대돼도 피해 숫자가 뜨는 높이와 겹치지 않습니다. 문구는 캐릭터를 따라다니므로 넉백으로 밀려나도 그 캐릭터에 붙어 있습니다.
  - 타격으로 깨질 때와 발검처럼 기술 효과로 깨질 때 모두 뜹니다.
  - 기존 붕괴 카메라·슬로·금색 큰 숫자 연출은 그대로입니다. 발검처럼 기술 효과로 깨질 때는 지금처럼 카메라 연출이 없습니다.
- **회복 순간 문구:** 턴이 시작되며 저항이 자동으로 다시 차면 "저항 회복"이 떠오릅니다.
- **피해 숫자 색:** 저항 피해는 저항 게이지와 같은 강철색 숫자(짙은 청회색 테두리)로 표시합니다. 체력 피해는 지금처럼 상아색(강조 시 금색) 숫자입니다.
  - 저항 피해는 강조 조건(표시 피해 12 이상)이어도 강철색을 유지하고 크기만 커집니다.
  - 강철색은 숫자가 잃은 저항과 같을 때만 씁니다. 저항을 깨뜨린 타격은 넘친 체력 피해만 표시하므로 체력 피해 색입니다. 넘친 피해가 없으면 지금처럼 "0"을 체력 피해 색으로 표시하고, 붕괴는 "붕괴 ×2" 문구가 알립니다.
- 문구는 반격 문구와 같은 방식이지만 별도 풀(`State Callout`, 최대 4개)을 씁니다. 피해 숫자는 바깥쪽, 반격 문구는 안쪽, 이 문구는 허리 높이에 떠서 서로 겹치지 않습니다.

## 코드 위치

| 역할 | 위치 |
|---|---|
| 이펙트 모양(윤곽 두께, 색, 맥동 주기, 고리 모양) | `Presentation/DuelBreakAura.cs` |
| 윤곽·고리 셰이더 | `Resources/DuelVFX/BreakSilhouette.shader` (색은 렌더러별 `_Tint`로 넘깁니다. URP 17은 스프라이트 색을 정점 색으로 넘기지 않습니다.) |
| 이펙트 켜기·끄기 | `LegacyArenaView.SetResistanceBroken(player, enemy)` |
| 붕괴·회복 감지 | `DuelPrototypeController.AnnounceBreaks`, `StartPlanning` |
| 문구 문자열·숫자 색 | `LegacyCombatHud.BreakCalloutText`, `RecoveryCalloutText`, `ResistanceDamageInk` |

이펙트는 코드로 그린 임시 그림입니다. 아트로 바꿀 때는 `DuelBreakAura`만 교체하면 됩니다. 셰이더를 불러오지 못하면 경고를 남기고 이펙트 없이 전투를 진행합니다.

## 검증

- Presentation과 PlayMode 테스트는 컴파일만 확인했습니다. Unity에서 실행하지 않았으므로 화면 확인이 필요합니다. 특히 볼 부분은 다음과 같습니다.
  - 윤곽 두께(2픽셀)와 색이 잘 보이는지
  - 고리가 그림자 위에 제대로 깔리는지
  - 문구 위치(허리 높이)가 적당한지
  - 셰이더가 2D Renderer에서 그려지는지
- 새 PlayMode 테스트 `BreakPresentationPlayModeTests` 5개를 추가했습니다(다섯 번째는 2026-09-30 스텝 개편 때 추가).
  - 이펙트가 캐릭터 프레임을 따라가고 전투 시계로 켜지고 꺼지는지
  - 전장에서 깨진 캐릭터에만 이펙트가 붙는지
  - 저항 숫자 색과 문구 풀
  - 실제 컨트롤러에서 발검 붕괴·타격 붕괴·턴 시작 회복 문구가 뜨는지
  - 집중 카메라가 붕괴와 마무리 일격에만 걸리고, 큰 피해는 금색 숫자만 받는지
- 전투 규칙 코드는 바꾸지 않았습니다. EditMode 테스트는 그대로 통과합니다.

## 알려진 점

- 붕괴된 그 턴에 투지를 쓰면 저항이 조금 회복되면서 붕괴가 풀립니다. 이때 원래 예정되어 있던 자동 완전 회복이 사라집니다. 기존 규칙이고, 지금 캠페인 적은 투지를 쓰지 않습니다. 의도한 규칙인지 확인이 필요합니다.
- 최대 저항이 0인 전투(테스트 전용)에서는 처음부터 끝까지 붕괴 상태라 이펙트가 계속 켜져 있습니다.
