# 전투 가시성: 현재 합·피해 원인·접촉 구도

## 스킬 위력의 압력 연출 (2026-10-26)

위력 차 붕괴 시험 규칙에서 실제 사용하는 모든 플레이어 스킬의 위력 숫자에 압력 연출을 연결한다.
공격 합에만 제한했던 첫 구현의 범위를 바로잡아 방어·회피·숨고르기·일방공격에도 같은 연출을 보여 준다.
적은 확정 위력을 그대로 보여주며, 플레이어는 **0에서 이미 추첨된 최종 위력까지** 0.45초 동안 올라간다.
기존 숫자 아래의 작은 게이지가 차고, 최종값 도달 순간 기존 증기 그림으로 짧은 방출 FX와 숫자 강조를 표시한다.
확정 후 0.12초를 더 확보하고 공격 동작을 이어간다. 방출 증기는 0.32초 동안 퇴색하며 공격 초반과 겹친다.
새 기계 패널·압력 문구·별도 숫자판은 추가하지 않는다.

`DuelPowerPressure`는 실제 시간만 읽는 표시 시계다. 두 컨트롤러는 압축/확정 구간 동안 전투·공격 시계를 0으로 두고
HUD만 진행한다. 수훈 컷인의 남은 시간은 먼저 소비한다. 같은 기술의 연타나 피드백 갱신은 압축을 다시 시작하지 않으며,
슬로모션·후반 재생 가속은 이 판독 시간을 줄이지 않는다. 메인의 스텝 판정은 압축 뒤 원래 입력창에서 진행한다.

고속과 차지 기술도 실제 기술이 완료되어 위력이 추첨된 시점에 압축한다. 준비 중인 긴 기술이나 기술이 없는 빈 구간에
가짜 숫자를 만들지 않는다. 지연 반격은 기존 첫 접촉 준비가 실제 반격과 위력을 확정한 뒤 압축하고 실제 타격을 이어 간다.
준비 중인 기술을 미리 추첨하거나 전투 RNG를 더 소비하지 않는다. 숫자 충돌·파쇄·위력 차 붕괴는 공격 합에서만 적용한다.
온라인 두 시점은 같은 구간에 동일한 길이의 정지를 사용하고 각 화면의 내 위력만 채운다. 상대만 기술을 완료한 관점은
내 게이지를 만들지 않고 같은 시간만 기다리며 상대의 확정 숫자를 보여 준다.
압축 중에도 현재 진행도에 맞는 전투 카메라 요청을 유지해 대기 적 전체를 담는 구도로 풀리지 않게 한다.
조작대의 남은 접힘만 실제 시간으로 진행하고 전투·슬롯·큐 진행 시계는 멈춘다.
HUD 숨김·새 전투·턴 전환·Reset은 숫자/게이지/증기를 함께 정리한다. 전투 규칙·피해·자원·네트워크 메시지는 바꾸지 않는다.

2026-10-18. 최신 기준 커밋 `f1aa66c`의 다인전·붕괴 예약 취소·교전 카메라 위에 적용한다. 전투를 보면서 어떤 기술끼리 맞붙고, 누구에게 무슨 일이 생겼으며, 피해가 왜 달라졌는지 읽도록 한다. 턴 전체 요약은 추가하지 않는다.

## 현재 합

- 기존 큐 중앙 위의 고정 두 줄 판에서 내 기술과 상대 기술, 실제 결과를 읽는다. 첫 타격 전에는 `맞붙는 중`이며, 이후 `상대 방어 관통`, `내 회피 성공`, `서로 저항 손실`, `상대 저항 붕괴·체력 손실` 등으로 갱신된다. 공격 대 공격의 양쪽 피해를 승리/패배로 단순화하지 않는다.
- 다인전은 실제 현재 상대의 번호·이름을 합 시작 때 캡처한다. 쓰러진 적을 친 결과가 다음 생존자의 이름으로 바뀌지 않는다. 기존 카드 소유자 번호·긴 큐 표시 구간·붕괴 파편은 유지한다.
- 같은 프레임에 끝난 마지막 합도 완료 전에 관찰해 다음 합/편성까지 보존한다. 판은 큐 장식과 코치 위에 자리하고 입력을 가로채지 않는다. 기존 HUD 침범 방지 높이에 포함되며 다음 턴·재시작에서 지운다.

## 피해 숫자

- 숫자 아래에 `내 체력`, `상대 저항`, 다인전의 `상대 2 체력`처럼 피격 대상과 자원을 적는다. 실제 계산에 반영된 핵심 이유 하나를 붙인다: `붕괴 ×2`, `체력 30% 이하 ×2`, `붕괴 추가 +100%`, `압박 추가 피해`, `방어 감소` 등.
- 조건 충족만으로 피해 배율을 표시하지 않는다. 실제 연산이 수치를 바꿀 때 원인을 기록한다. 저항에 흡수된 조건 공격과, 방어를 통과하는 압박 추가 피해에 붕괴 배율을 잘못 붙이지 않는다.
- 이유가 겹치면 압박 추가 → 조건 배율 → 붕괴 추가 → 붕괴 2배 → 방어 압박 → 방어 → 보호 순서로 하나만 표시한다. 전체 계산식을 나열하는 기능은 아니다.
- 압박의 체력 피해와 본타격의 저항 피해가 한 숫자로 합산되면 `체력·저항`으로 표시한다. 붕괴 타격의 체력 넘침 숫자는 체력으로 표시한다.
- 붕괴를 만든 첫 타격은 기존처럼 넘친 체력 피해가 2배가 아니다. 붕괴 순간은 `저항 붕괴`, 실제 2배가 적용된 후속 타격은 `붕괴 ×2`로 구별한다. 체력 넘침 없는 붕괴의 큰 `0`은 생략하고 사건을 보여 준다. 일반 완전 방어의 0은 유지한다.
- 숫자와 설명은 같은 풀·실제 시간 수명·페이드를 공유한다. 재사용 때 이전 이유를 지우고, 떠 있는 설명은 상대 교대 뒤에도 그 타격의 대상을 유지한다.

## 접촉을 읽는 카메라

- 기술을 시작하면 첫 접촉까지 두 사람의 관계를 확보한다. 실제 타격·회피·효과 판정 뒤 **실제 시간 0.14초**와 **최소 한 카메라 프레임** 동안 플레이어와 현재 상대를 함께 보여 준다. 긴 프레임에서 판독 구간 전체가 사라지는 것을 막고 연타의 다음 접촉에도 새 구간을 준다.
- 이후 기존 주인공 중심 결정타·마무리 클로즈업으로 이어진다. `IsFatalFocus`와 슬로모션 수명, 타격 정지·입력창·애니메이션·턴 진행 시간은 바꾸지 않는다. 판독을 위해 전투를 추가 정지하지 않는다.
- 몸·발·검이 맞닿는 영역은 기존 카메라의 고정 인물 여백을 사용한다. 투명 여백이 큰 스프라이트 전체 사각형으로 화면을 넓히지 않는다. 대기 중인 다른 적도 판독 구도를 넓히지 않는다.
- 추적 보간·카메라 기울기·흔들림을 적용한 최종 구도에서 두 사람의 영역이 화면 좌우/상단 여백과 HUD 위에 들어가도록 필요한 만큼만 보정한다. 기존 구도가 안전하면 그대로다. 접촉 뒤의 클로즈업과 장면 컷인의 구도는 각 연출이 담당한다.
- 컷신·일시 정지에서는 새 판독 시계도 진행하지 않는다. 다음 합은 이전 판독 상태를 버리고 첫 접촉을 기다리며, 턴 종료는 방금 결과의 짧은 판독을 보존한다. 새 턴·재시작은 전부 초기화한다.

## 구조와 검증

`LegacyClashReadout`은 실제 합의 사실을 문구로, `LegacyDamageReason`은 실제 피해 연산의 변화를 핵심 이유로 만든다. `LegacyContactReadWindow`와 `LegacyContactCamera`는 Unity에 의존하지 않는 표시용 시계·구도 계산이다. HUD와 arena의 `.Readability.cs`가 이를 기존 생성 경로에 연결하며 추가 Inspector 설정은 없다.

기존 전투 계산·난수 소비·저장 형식·대전 상태 해시·최신 붕괴 예약 취소 규칙을 유지한다. 회사 PC에서는 독립 C# 테스트와 구문 검사를 사용한다. 실제 Unity 타입 컴파일, PlayMode, 화면 배치·연출 속도에서의 가독성과 온라인 두 장치 동작은 별도 확인이 필요하다. 구체적인 실행 결과는 `Validation.md`를 따른다.
