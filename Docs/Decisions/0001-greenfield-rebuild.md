# 0001. Greenfield Rebuild With Selective Asset Migration

- Status: Accepted
- Date: 2026-09-26

## Context

레거시 프로젝트는 Unity 2021에서 Unity 6.5로 직접 전환되었고, 오래된 플러그인, 전역 singleton, 단일 대형 전투 컨트롤러, 런타임 CSV/Reflection, 테스트 부재가 결합되어 있다. 출시 가능한 개선작을 목표로 할 때 복구와 구조 개선을 동시에 수행하면 작업 범위가 쉽게 커진다.

## Decision

공식 Unity 6 Universal 2D 템플릿으로 신규 프로젝트를 만들고, 전투 코어와 런타임 구조를 새로 구현한다. 레거시 프로젝트는 읽기 전용 참고 자료로 유지하며 검증된 리소스와 콘텐츠 의도만 선별 이식한다.

## Consequences

- 레거시 실행 복구에 자원을 쓰지 않는다.
- 초기에는 화면보다 테스트 가능한 전투 규칙 구축이 우선이다.
- 기존 씬과 프리팹을 재사용하는 대신 새 구조에서 다시 조립한다.
- 리소스마다 라이선스 및 호환성 검증 비용이 발생한다.
- 우선 원본 첫 전투의 기술 큐·ACT·충돌·턴 전환을 기준 동작으로 이식한다. 이 단계에서 새 전투 규칙을 임의로 만들지 않는다.

## 원본 전투 확인 단계

사용자 요청에 따라 즉시 행동형 최소 실험 화면을 원본의 큐 편성형 전투로 교체했다. 기본 9개 기술과 첫 상대, 기존 리소스로 먼저 한 판을 확인하며 스텝 등 개선 규칙은 이후 별도 기획한다. 이번 로컬 리소스 이식에는 원본 `.meta`의 분할·피벗을 유지한다.
