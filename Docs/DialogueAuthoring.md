# 다이얼로그 작성 가이드

## 목적

다이얼로그는 C# 코드나 Unity 씬을 수정하지 않고 UTF-8 텍스트 파일로 작성한다.
한 파일은 처음부터 끝까지 순서대로 재생되는 하나의 대화 장면이다.

프로젝트에는 예시 스토리 내용을 넣지 않는다. 직접 만들거나 편집기가 생성한 빈 파일은 있을 수 있다.
실제 집필은 `Assets/Game/Resources/Dialogue/` 아래의 `.txt` 파일에서 진행한다.

Unity 안에서 작성하려면 상단 `Turn Limbo → 다이얼로그 편집기`를 사용한다. 새 파일·자동 저장·실시간 규칙 검사·빠른 입력·화자 이미지 지정·미리보기를 제공하며, 자세한 사용법은 `DialogueEditor.md`에 정리한다.

## 빈 작성 형식

아래 표기는 문법 자리표시자이며 스토리 예시가 아니다.

```text
# 이 줄은 작성 메모이며 게임에 표시되지 않는다.

@narrator
<한 번에 표시할 나레이션>

@left <화자 이름>
<한 번에 표시할 왼쪽 화자의 대사>

@right <화자 이름>
<한 번에 표시할 오른쪽 화자의 대사>
```

## 작성 규칙

- 빈 줄과 `#`으로 시작하는 줄은 게임에서 무시한다.
- 지시어가 나오기 전의 일반 문장은 나레이션이다.
- `@narrator`는 이름표가 없는 나레이션으로 전환한다.
- `@left 이름`과 `@right 이름`은 화면 왼쪽·오른쪽 화자를 등록하고 선택하며, 해당 위치의 화자 이미지를 자동으로 표시한다.
- 역할이나 호칭이 필요하면 `@left 이름 | 역할`처럼 `|` 뒤에 적는다.
- 해당 위치에서 마지막으로 지정한 화자를 계속 사용할 때는 이름 없이 `@left` 또는 `@right`만 적을 수 있다.
- 일반 문장 한 줄이 플레이어가 한 번 넘기는 단위다. 한 줄은 공백을 포함해 최대 240자이며, 넘으면 줄 번호와 함께 오류가 난다. 긴 내용은 의미가 끊기는 지점에서 다음 표시 줄로 나눈다.
- 실제 표시 문장이 `@` 또는 `#`으로 시작해야 하면 `\@`, `\#`으로 적는다.
- 줄 전체를 괄호로 감싼 문장 `( … )`은 **독백**(속마음)이다. 괄호는 그대로 보이고, 본문이 독백 색(차분한 푸른 회색)으로 바뀐다. 말하는 화자가 있든(`@left 엘리사`) 나레이션이든 같고, 컷신의 대사와 전투 중 말풍선(`Barks.md`)에도 똑같이 적용된다. 앞뒤 공백은 무시하지만, 괄호가 줄의 일부만 감싸면(`(생각) 하고 말했다`) 보통 대사다. 반각 괄호 `(` `)`만 해당하고 전각 `（` `）`는 해당하지 않는다.
- 지시어는 소문자 그대로 적는다. `@Left`처럼 대소문자가 다르면 인식하지 않는다.
- 화자 선언의 `|`는 역할·호칭을 적을 때만 한 번 사용할 수 있다. 역할이 없다면 `|`도 쓰지 않는다.
- 파일명은 영문 소문자·숫자·하이픈 조합을 권장한다. 예: `chapter-01-intro.txt`.
- 현재 폰트는 한글과 일반 문장부호를 기준으로 한다. 이모지와 일부 한자는 표시를 보장하지 않는다.

잘못된 지시어나 비어 있는 화자 이름이 있으면 파일 ID와 원본 줄 번호를 포함한 오류를 남기고 대화를 열지 않는다.

## 화자 이미지 무대 문법

아래 표기의 `<...>`는 작성할 값이고 `[...]`는 생략할 수 있는 부분이다. 문법 자리표시자이므로 괄호 자체를 원문에 적지 않는다.

```text
@show <left 또는 right> [<화자 이름> | <역할·호칭>]
@hide <left 또는 right>
@move <left 또는 right> <left 또는 right>
```

- `@show left`와 `@show right`는 해당 위치에 마지막으로 등록한 화자 이미지를 다시 표시한다.
- `@show left <화자 이름>`처럼 이름을 함께 적으면 해당 위치의 화자를 등록하거나 교체하면서 표시한다. 역할·호칭은 `|` 뒤에 선택적으로 적는다.
- `@hide left`와 `@hide right`는 해당 위치의 화자 이미지를 퇴장시킨다. 이미 비어 있는 위치를 숨기려 하면 오타를 잡을 수 있도록 오류로 처리한다.
- 이동은 `@move left right` 또는 `@move right left`로 적는다. 출발 위치의 이미지가 현재 보여야 하며 목적지 위치는 비어 있어야 한다.
- 표시된 화자 이미지는 `@hide`, 다른 화자로 교체하는 선언, 또는 `@move`가 나오기 전까지 유지된다. 한쪽이 말해도 다른 쪽 이미지는 사라지지 않는다.
- 현재 말하는 화자 이미지만 밝게 표시하고, 나머지 화자 이미지는 어둡게 표시한다. 나레이션 중에는 양쪽 이미지를 모두 어둡게 표시한다.
- `@show`, `@hide`, `@move`는 화면 상태만 바꾸는 무대 명령이다. 플레이어가 넘기는 표시 줄 수와 진행 번호에는 포함되지 않으며, 다음 실제 문장에 반영된다.

## 자주 생기는 입력 오류

- `@left` 또는 `@right`를 먼저 선언하지 않고 이름 없이 사용함
- 해당 위치에 화자를 등록하지 않고 이름 없는 `@show left` 또는 `@show right`를 사용함
- 이미지가 보이지 않는 위치에서 이동하거나, 이미 차 있는 위치로 이동함
- 이미 비어 있는 위치에 `@hide`를 사용함
- `@move left left`처럼 출발 위치와 목적지를 같게 적음
- 현재 말하는 화자를 숨긴 뒤 `@narrator`, `@left`, `@right` 중 하나로 다음 화자를 지정하지 않고 일반 문장을 적음
- 역할을 비워 둔 채 `이름 |`처럼 `|`만 남김
- 한 화자 선언에 `|`를 두 번 이상 사용함
- 지원하는 지시어 이외의 명령을 사용하거나 무대 명령의 위치·인수 개수를 잘못 적음
- 주석과 지시어만 있고 실제로 표시할 문장이 없음

오류가 나면 Console에 표시된 파일 ID와 줄 번호를 먼저 확인한다.

## 개발자 연결 참고

파일이 `Assets/Game/Resources/Dialogue/chapter-01-intro.txt`라면 Presentation 계층에서 다음처럼 연다.

```csharp
controller.StartDialogue("Dialogue/chapter-01-intro");
```

독백인지는 `DialogueLine.IsMonologue`(규칙은 `DialogueLine.IsMonologueText`)가 판단하고, `DialogueHud`가 본문 색(`DialogueHud.MonologueColor`)을 바꾼다.

확장자 `.txt`는 로드 경로에 쓰지 않는다. 현재 로비 홈 화면의 `스토리` 버튼은 `Assets/Game/Resources/Dialogue/dialogue.txt`, 즉 `Dialogue/dialogue`를 연다. 씬이 시작되자마자 자동으로 재생하지는 않는다.

스토리 임무는 시작 장면과 종료 장면(승리 뒤, 4 임무는 수훈 뒤의 패배 뒤)을 자동으로 재생한다. 먼저 전장 컷신 `Cutscene/mission-NN-intro`·`-outro`(`Cutscene.md`)를 찾고, 없으면 대사 `Dialogue/mission-NN-intro`·`-outro`를 재생한다(NN은 서막 `01`~`04`, 수련 `05`~`09`). 서막 네 임무의 장면은 원고로 쓴 컷신이고, 수련 임무는 아직 `테스트` 한 줄짜리 대사다. 4 임무 전투 중의 수훈 장면도 같다(`Cutscene/mission-04-event`, 없으면 `Dialogue/mission-04-event`). 장면은 끝까지 넘기거나 Escape로 건너뛰면 다음 단계로 넘어간다. 시작 장면은 전투, 종료 장면은 결과 창, 4 임무의 종료 장면은 로비(서막을 마침), 수훈 장면은 수훈이 적용된 채 이어지는 전투다. 상세는 `PrologueMissions.md`와 `StoryUnlocks.md`를 따른다.
첫 버전의 시작 API는 안전한 상태 전환을 위해 로비에서만 대화를 열도록 제한되어 있다.

## 기본 조작

- 마우스 클릭, Enter, Space: 다음 줄
- Escape 또는 닫기 버튼: 현재 대화 닫기
- 대화 중에는 뒤쪽 로비·전투 입력을 받지 않는다.

## 첫 버전 범위

현재 버전은 선형 대화, 좌우 화자, 이름·역할, 나레이션, 화자별 공용 기본 이미지 한 장과 이미지의 등장·퇴장·좌우 이동을 지원한다.
선택지, 분기, 조건, 변수 치환, 표정별 이미지 전환, 저장 지점은 스토리 구조가 정해진 뒤 필요한 것만 확장한다.
배경·카메라·인물을 움직이는 장면은 대화가 아니라 컷신(`Cutscene.md`)으로 쓴다. 컷신은 이 문서의 대사 문법을 그대로 쓰고 연출 명령을 더한다.
