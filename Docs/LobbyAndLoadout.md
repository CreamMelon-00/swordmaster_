# 방 로비·스테이지 선택·스킬 편성

2026-09-27. 레거시 `OutGame`에서 계승한 방의 홈이 로비의 첫 화면이다. 2026-09-30부터 Play는 서막 임무 브리핑에서 시작하고, 네 임무를 마친 뒤 이 홈이 열린다(`PrologueMissions.md`). 기존의 전투 사이 정비 화면을 기본 진입점으로 쓰지 않는다. 홈·스테이지·편성·상점은 방 위에 작은 팝업을 겹치는 방식이 아니라 고정 상단 메뉴 아래에 각자 화면을 채우는 페이지로 표시한다. 전투 중 스킬 설명과 전투 결과 창은 기존의 상황별 팝업이다.

## 전체 화면 구성과 전환

- 공통 상단: 검술 클럽 이름, 진행·개방 단계, 홈/스테이지/편성/상점 메뉴, 재화를 고정된 위치에 둔다. 페이지 전환 연출은 본문에만 적용하며 상단 메뉴는 계속 사용할 수 있다.
- 홈: 방 배경을 넓게 보여주고 왼쪽 준비 메뉴는 상단을 제외한 화면 높이를 채우는 세로 레일로 배치한다. 출정·편성·상점과 진행 요약을 이 레일에 모은다.
- 스테이지: 8개 카드를4열×2행으로 배치한다. 오른쪽 미리보기에서 선택한 단계의 풍경·이름·적 체력/저항/위력·보상·출정 가능 상태를 확인하고 도전한다.
- 편성·상점: 본문 영역을 넓혀 기술열/보유 목록 또는 구매·강화 목록과 오른쪽 선택 상세가 각 페이지의 중심이 되게 한다. 선택 상세는 공용 스킬 정보 카드의 숫자·의미별 색 배지·짧은 조건을 사용한다. 카드 클릭은 선택만, 위치 변경은 드래그만, 거래는 별도 버튼만 수행하는 기존 UX를 유지한다.

다른 메뉴로 이동하면 새 페이지가0.22초 동안 페이드인하며 메뉴 순서에 따라 좌우32px에서 제자리로 들어온다. `LobbyScreenTransition`은 `Time.unscaledDeltaTime`을 사용하므로 전투의 느린 재생이나 `Time.timeScale`과 무관하게 움직인다. 전환 도중 새 본문의 클릭·드래그는 잠시 차단하고 완료 시 복원한다. 상단 메뉴를 빠르게 연속 선택하거나 로비를 숨기는 경우 진행 중 연출을 종료하고 원래 위치·투명도·입력 상태로 정리한다. 같은 메뉴의 거래·선택 갱신은 페이지 이동 연출을 반복하지 않는다.

화면 전환은 표현만 바꾼다. 선택한 스테이지, 편성의 선택 열/기술과 보유 목록 스크롤, 상점의 구매·강화 분류/선택/스크롤을 보존한다. `CampaignRun`의 미저장 편집은 페이지를 오가도 남으며 출정 차단·각열3개·총9개 저장 규칙은 바뀌지 않는다. 여정 초기화 또는 다른 여정으로 바뀔 때만 해당 뷰 상태를 초기화한다.

## 조작과 흐름

- 홈: 방을 배경으로 출정·스킬 편성·상점으로 이동한다.
- 스테이지: 8개 카드에서 열린 단계를 선택한 뒤 도전 버튼 또는 Enter로 입장한다. 카드 선택 자체는 전투를 시작하지 않는다. 처음엔 1단계만 열리고 최초 클리어마다 다음 단계를 연다. 클리어한 단계도 재선택할 수 있다.
- 편성: Q 정공/W 강공/E 기교 검술 각각 정확히 3개씩, 총 9개를 저장한다. 검술 이름·키·염색 종이 표식을 열 제목과 선택 상세에 표시하고 보유 목록 필터도 같은 이름을 쓴다. 카드는 순서·아이콘·이름·ACT만 표시하고 선택한 기술의 용도와 실제 효과만 오른쪽 상세에 표시한다. 기본 9개는 처음부터 저장되어 있다. 검술 분류는 공격 타입이나 새 효과가 아니며 기존 열 소속을 유지한다.
- 선택·순서·교체: 카드 클릭은 설명 선택만 수행하고 편성이나 순서는 바꾸지 않는다. 같은 열 안에서 카드를 원하는 슬롯으로 끌면 서로 자리를 바꾼다. 아래 보유 목록은 선택한 열의 기술만 보여주며 보유 기술을 슬롯으로 끌면 교체한다. 위치 변경과 교체는 드래그로만 진행한다. 다른 열로 이동·중복 편성은 허용하지 않는다.
- 저장·되돌리기: 모든 편성 조작은 임시 편집이다. 해제하면 빈 슬롯이 남으며 빈칸이 하나라도 있으면 저장 버튼을 비활성화한다. Q/W/E의 개수와 부족한 열을 하단에서 확인한다. 저장은 9개 전체를 한 번에 적용하고 되돌리기는 마지막 저장 상태를 복구한다. 탭을 오가도 임시 편집은 남는다. 미저장 변경이 있으면 출정할 수 없으므로 저장하거나 되돌린다.
- 상점: 구매/강화 탭을 나눠 한 종류의 목록만 보여준다. 카드는 아이콘·이름·ACT·획득 상태 또는 강화 단계만 표시한다. 클릭은 설명 선택만 수행하며 실제 거래는 오른쪽의 구매/강화 버튼으로만 요청한다. 선택한 기술의 효과·가격·재화 부족 이유와 강화 전후 위력은 상세 한 곳에서 확인한다. 획득 완료/최대 강화/재화 부족은 거래 버튼을 비활성화한다. 거래와 탭 이동 후에도 선택과 스크롤을 유지한다. 구매는 소유 목록에만 추가하므로 사용하려면 편성에서 드래그로 교체하고 저장한다. 강화는 장착 여부와 무관하게 소유 기술에 적용된다.
- 전투 종료: 전장 위 결과 창에서 승패·보상·해금을 확인한다. 로비/재도전/개방된 다음 스테이지를 직접 선택하며 Enter/Escape는 결과를 닫고 방으로 돌아온다. 구매·편성·재화·강화·해금은 유지한다. 8단계를 모두 끝내도 로비/재도전을 선택할 수 있다. 전투 중 Escape는 보상 없이 중단해 방으로 돌아온다. 로비 Escape는 홈으로 이동한다.
- 로비는 서막 임무 네 개를 마친 뒤에 열린다(`PrologueMissions.md`). 이전의 기초 연습 버튼은 서막 임무로 대체해 삭제했다.

전투 입장은 HP100/저항50/ACT3/편성10초로 회복하고 실제 편성한 순서만 전투 기술열에 전달한다. 로비 동안 전투 타이머·애니메이션·판정은 진행하지 않는다. Enter는 스테이지 탭의 출정에만 사용해 상점 구매나 편성 조작과 겹치지 않게 한다.

첫 클리어 보상은 기존 60~130, 재클리어 보상은 그 절반인30~65이다. 한 전투의 보상은 한 번만 지급하며 패배/중단은0이다. 최초 보상으로 다음 스테이지 해금·정비를 진행하고 필요하면 낮은 단계 재도전으로 재화를 얻을 수 있다. 진행은 Play 세션 안에서만 보관한다. 디스크 저장은 아직 없다.

## 역할이 읽히는 아이콘

| 역할 | 테두리 실루엣 | 색 | 중심 문양 |
|---|---|---|---|
| 베기 | 마름모 | 주황 | 휘두르는 검/교차 검 |
| 관통 | 세로 육각형 | 청록 | 직선 찌르기/과녁 |
| 타격 | 넓은 홈 파인 사각형 | 금색 | 검 내려치기/충격 |
| 방어 | 방패형 테두리 | 녹색 | 검으로 막기/흘리기/쳐내기 |

색만으로 판단하지 않도록 모양과 문양을 함께 나눴다. 무기 문양은 검만 사용한다. 전투의 현재 카드에는 스킬 이름도 표시한다. 편성 카드에는 이름·ACT만 남기고 세부 역할·위력·효과는 선택 상세에 모은다. 상점도 선택한 기술에만 상세 효과를 표시하고 목록 카드는 간결하게 유지한다. ACT 회복/후속 위력/피해 감소는 고유 표식, 순수 고화력은 큰 섬광, 연타는 반복 궤적으로 구분한다. 추가 기술6개에는 미이식 효과를 약속하지 않는 별도 `IconId`10~15를 할당한다. 모든 소비자는 같은 atlas를 사용한다. 기존 키캡 PNG·레거시 퍼즐 이미지는 보존한다. 자세한 실제 의미와 조건부 저항 피해는 `SkillRoleLanguage.md` 참조.

최신 아이콘은 내장 이미지 생성 도구로 편집한 투명 alpha의15개 atlas이며3열5행으로 나눈다. Point / 무압축 / Mipmap 없음 / Clamp로 사용한다. `Resources/SkillRoles/skill-role-atlas.png`는 프로젝트 안에 보관한다. AI 원본이 완벽한48px 격자·색상 수를 보장하는 것은 아니며 작은 실제 카드에서 역할 판독을 확인한다. 최신 프롬프트와 크기/임포트 기록은 `Art/SwordSkillIcons.md`, 이전9개 제작 기록은 `Art/RoleSkillIcons.md`에 있다.

방 원본 경로·씬 참조·복사 일치는 `LobbyRoomAssets.md`를 따른다. 스테이지 수치·강화/가격·추가 기술의 미이식 고유 효과는 `CampaignLoop.md`를 따른다. 그 문서의 전투 사이 정비 UI는 이전 흐름이며 현재 진입/편성은 이 문서가 우선한다.

## 구현

`CampaignRun`이 해금·보상·재화·소유·저장 편성과 임시 편집을 소유한다. UI는 요청만 전달한다. 저장은 소유권·중복·고정 열·각 3개를 전부 검사한 뒤 원자적으로 적용한다. `CreateDuel`은 임시 편집이 아닌 마지막 저장 편성의 강화된 스킬을 스냅샷으로 만든다. `DuelPrototypeController`는 로비/전투/결과 입력을 분리하고 전투 종료 후 결과를 먼저 표시한다. `CampaignLobbyHud`가 상단과 현재 전체 페이지, 편성·상점의 보존 뷰 상태를 소유하고 `LobbyScreenTransition`은 새 페이지의 시각적 진입만 담당한다. 페이지는 기존 로비 Canvas 안의 런타임 UI이며 별도 Unity 씬으로 나누지 않는다. 기존 큐/ACT/피해/연출은 변경하지 않는다. 별도 씬 저장·패키지 추가·레거시 복구는 없다. `RestartJourney`는 새 로비, 이전 검사/API용 `RestartMatch`는 새1스테이지 전투다. 여기서 편성 저장은 현재 Play 세션 안의 적용이며 디스크 저장은 아니다. 서막 임무의 Q열은 일반 편성 저장 대상이 아니다.

검증 근거와 초기 밸런스·지원 화면 범위는 `Validation.md`의 최신 항목에 기록한다.
