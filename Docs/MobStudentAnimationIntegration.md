# 모브 주인공 애니메이션 연결

현재 리뉴얼 프로젝트의 `LegacyArenaView`에서 플레이어를 모브 캐릭터로 교체했다. 적, 전투 판정, 스킬 데이터, 피해량, HUD와 이동 거리는 유지한다.

## 재생 규칙

- 플레이어 상반신과 하반신은 서로 다른 `SpriteRenderer`를 사용한다. 상반신에는 검과 두 손이 포함되고, 하반신은 치마·골반·두 다리로 이어진 한 장이다.
- 참격은 `slash-1..3`, 관통은 `pierce-1..3`, 타격은 `blunt-1..3`에 대응한다. 기술의 실제 타격 순번이 1→2→3을 선택하며, 4타 이상은 1부터 반복한다. 단타 기술은 각 속성의 1타를 사용한다.
- 각 공격은 준비→가속→접촉→회수 4프레임이다. 기존 한 타 길이 1/6초와 임팩트 1/12초를 유지하며, 접촉은 세 번째 프레임에서 발생한다. 재생 배율·히트 스톱·연타 간격은 기존 전투 시계를 그대로 따른다.
- 대기 상반신은 4프레임을 프레임당 0.14초로 반복한다. 방어는 새 캐릭터의 검을 든 대기 자세를 사용한다.
- 하반신은 실제 X 변위가 있을 때 8프레임을 독립적으로 재생한다. 기존 접근·추격의 이동 거리 진행률, A/D 스텝의 시간 진행률을 하반신 한 주기에 맞춘다. 별도의 진행률이 없는 외부 이동은 프레임당 0.14초 시계를 사용한다. 전진은 순방향, 후퇴는 역순이며 얼굴·발을 좌우 반전하지 않는다. 이동이 멈추면 기본 가드 하반신으로 돌아간다.
- 히트 스톱은 상·하반신을 함께 유지한다. 실제 시간으로 이동하는 A/D 스텝은 정지한 공격 시계와 독립적으로 하반신을 재생할 수 있다. 이동 잔상은 현재 상반신과 하반신을 함께 보존한다.

## 리소스와 좌표

리소스는 `Assets/Game/Resources/MobStudent/Animations` 아래에서 로드한다.

| 경로 | 수량 |
| --- | ---: |
| `idle/upper-1..4.png` | 4 |
| `idle/lower-1.png` | 1 |
| `move/lower-1..8.png` | 8 |
| `slash-1..3/upper-1..4.png` | 12 |
| `pierce-1..3/upper-1..4.png` | 12 |
| `blunt-1..3/upper-1..4.png` | 12 |

49개 모두 1024×768 캔버스, PPU 150, Point 필터, 공통 발 피벗을 사용한다. 기존 800×704 그림의 크기는 유지하며 X에 128px, Y에 64px을 더해 좌우·위쪽 검끝을 위한 투명 여백을 확보했다. 최종 그림 좌표에서 발 기준은 (448,704), 허리 기준은 (434,520)이다. Unity의 아래쪽 기준 피벗은 (448,64), 정규화 값은 (448/1024,64/768)이다. 그림과 피벗을 같이 옮겨 월드에서 캐릭터 위치는 유지된다.

원본 Sprite는 발 피벗을 유지한다. 기존 전장·HUD·밀림이 사용하던 플레이어 중심 원점을 보존하기 위해 `MobStudentAnimationSet`은 텍스처를 공유하는 런타임 Sprite를 한 번 생성하고 피벗 Y에 2.23×PPU를 더한다. 상·하반신에 같은 이동을 적용하여 발이 기존 그림자 위치에 놓인다. 새 캐릭터 높이는 약 3.23 월드 단위로 기존 플레이어의 약 3.22와 맞춘다.

생성된 Sprite는 전장 해제 시 정리한다. 이미지나 클립을 매 프레임 로드하거나 생성하지 않는다. 새 클립이 불완전하면 경고와 `HasRequiredAssets=false`를 남기며, 테스트는 49개 전체 로드를 요구한다.

## 적용과 검증

씬·프리팹 수동 연결은 필요하지 않다. Play를 다시 시작하면 기존 부트스트랩에서 새 리소스를 사용하는 전장이 만들어진다. 이전 플레이어 그림과 클립은 보존한다.

`MobStudentAnimationPlayModeTests`는 전체 리소스의 크기·피벗·필터, 9개 공격의 실제 36프레임, 세 번째 프레임의 접촉, 4타 반복, 독립적인 하반신 8프레임, 정지·재시작 및 상·하반신 잔상을 검사한다. 기존 애니메이션·전투 재생 속도·압박 잔상 검사는 새 주인공 프레임 이름에 맞춰 갱신하며 적의 원본 클립을 계속 검사한다.

이동의 월드 속도와 발 접지를 맞추는 루트 모션은 도입하지 않았다. 현재 이동 거리·속도·판정은 유지하며 하반신 표시만 이동 진행률에 맞춘다. 실제 렌더링 프레임 수가 제한되므로 짧은 0.08초 스텝에서는 원본 8장 전부가 화면에 나타나지 않을 수 있다. 추후 보폭과 이동 속도를 함께 조정할 수 있다.

## 후속 머리 방향 교정

`Art/Animations/MobStudentAttacks/head-turn-v2/creation-notes.md`의 타격 3종은 F1/F4에서 오른쪽, F2/F3에서 왼쪽을 보는 머리를 사용한다. 타격 상반신 12개 PNG만 교체하고 나머지 37개 PNG·49개 Sprite metadata·런타임 C#은 보존한다. 공통 캔버스·피벗·PPU와 4프레임 접촉 시계도 동일하다. 이는 해당 타격 그림의 시선 수정이며 전투 명중 대상이나 이동 방향 규칙을 바꾸지 않는다. 이번 그림 교체의 대상 6개 검사와 실제 전장 촬영 근거는 `Validation.md` 최신 절을 따른다.
