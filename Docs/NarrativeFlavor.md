# 서사 플레이버 대조표

2026-10-01. 프로토타입에 "최소한의 이야기가 있다"는 느낌을 주기 위한 네이밍·플레이버 텍스트다. 대사(`Dialogue/*.txt`)는 작가가 직접 쓰고, 이 문서는 그 바깥의 화면 문구만 다룬다.

**적용한 것(2026-10-01)**: 챕터명(깨어남·가르침), 서막·가르침 임무의 제목·목표·적 이름, 결과 창의 `서막` 표기. 적은 허수아비를 빼고 모두 **떠돌이 기사**로 통일했다('길손 기사'는 이질적이라 폐기). 코드: `PrologueMission.DefaultChapter`, `PrologueMissions.cs`, `LobbyMissions.cs`, `BattleResultHud.cs`, 관련 테스트.

**적용하지 않은 것**: 해금 문구, 연습 기술 설명, 스테이지 이름·적 이름, 로비 명사·안내, 브리핑 배경. 아래 표는 그 제안을 그대로 남긴다.

## 틀

한 문장: **노모스에서 갓 나온 엘리제가 숲에서 만난 떠돌이 기사에게 결투를 배우며 숲을 빠져나간다.**

- 플레이어 **엘리제**. 자기가 오토마타인 것을 모르고, 아무도 모른다. 아는 것도 가진 것도 없다.
- 상대는 한 사람, **떠돌이 기사**. 정체는 비워 둔다(세계관의 '편력기사' 자리). 로비의 방은 그가 눌러앉은 **거처**다.
- 무대는 **숲**. 8스테이지는 토너먼트가 아니라 숲을 빠져나가는 길이고, 길목마다 기사가 결투를 청한다 — 전 국민이 기사이고 분쟁을 결투로 가리는 나라라서 낯선 이와의 첫 인사가 칼이 된다.
- 지금 분량은 사립학교에 들어가기 **전**이다. 서임·재단·교황은 등장하지 않는다.

### 화면에 내지 않는 말

- 오토마타 · 누스 · 노모스 · 노에시스 · 위상 — 엘리제도 세계도 모르는 층이다. 톱니 모티프는 그림으로만 둔다.
- 신성제국 · 교황 · 재단 · 서임 — 숲 단계에서는 아직 멀다. 세계는 "기사"와 "결투"라는 두 단어로만 비친다.
- 떠돌이 기사의 이름 · 과거 — 인물 구성은 뒤로 미뤘다.

브리핑 라벨 형식 `{챕터} · 임무 N / 4`. 코드: `PrologueMission.Chapter`(서막은 `"서막"` 기본값, 수련은 `LobbyMissions.Chapter`).

|---|---|---|---|---|---|---|
| 1 | 첫 타격 | **처음 쥔 검** | 허수아비 | 허수아비 (유지) | 허수아비를 쓰러뜨린다 | 유지 |
| 2 | 맞서는 검 | **인사는 칼로** | 신입생 | **길손 기사** | 공격끼리 맞붙어 상대의 저항을 무너뜨린다 / 신입생을 쓰러뜨린다 | 맞부딪쳐 상대의 저항을 무너뜨린다 / 길손 기사를 쓰러뜨린다 |
| 3 | 막아내기 | **받아내는 법** | 신입생 | **길손 기사** | 상대의 내려치기를 막기로 받아낸다 / 신입생을 쓰러뜨린다 | 상대의 내려치기를 막기로 받아낸다 / 길손 기사를 쓰러뜨린다 |
| 4 | 마지막 결투 | **떠돌이 기사** | 선배 | **떠돌이 기사** | 제한 시간 안에 기술을 예약한다 / 선배를 쓰러뜨린다 | 제한 시간 안에 기술을 예약한다 / 떠돌이 기사를 쓰러뜨린다 |

- 적용 시 2·3의 적도 **떠돌이 기사**로 통일했다(작가 결정). 표의 '길손 기사'는 폐기한 안이다.
- 1의 허수아비는 떠돌이 기사가 세워 둔 연습용이다. 이름은 그대로 두고 대사에서 설명하면 된다.

### 가르침 (`LobbyMissions.cs`)

| N | 현재 제목 | 제안 제목 | 적 | 현재 목표 (1·2행) | 제안 목표 |
|---|---|---|---|---|---|
| 5 | 기교 검술 | 유지 | 선배 → **떠돌이 기사** | E열 기교 검술을 예약해 상대를 흔든다 / 선배를 쓰러뜨린다 | 기교 검술로 상대를 흔든다 / 떠돌이 기사를 쓰러뜨린다 |
| 6 | 숨 고르기 | 유지 | 〃 | 숨고르기로 상대의 방어를 흘려보낸다 / 선배를 쓰러뜨린다 | 숨을 골라 상대의 방어를 흘려보낸다 / 떠돌이 기사를 쓰러뜨린다 |
| 7 | 회피 | **피하는 법** | 〃 | A로 상대의 공격을 피한다 / 선배를 쓰러뜨린다 | 상대의 공격을 피한다 / 떠돌이 기사를 쓰러뜨린다 |
| 8 | 강공 검술 | 유지 | 〃 | W열 강공 검술로 큰 피해를 준다 / 선배를 쓰러뜨린다 | 강공 검술로 큰 피해를 준다 / 떠돌이 기사를 쓰러뜨린다 |
| 9 | 압박 | **몰아붙이기** | 〃 | D로 내 공격을 밀어붙여 큰 피해를 넣는다 / 선배를 쓰러뜨린다 | 내 공격을 밀어붙여 큰 피해를 넣는다 / 떠돌이 기사를 쓰러뜨린다 |

- 목표 3행("완료하면 E열이 열린다" 등)은 시스템 안내이므로 유지한다.
- 수련 임무의 적 기술 '연습 베기·연습 내려치기·연습 막기' 설명이 "훈련용 검으로"인데, 떠돌이 기사의 것이므로 **"무딘 검으로"**가 맞는다. 이름은 그대로 둔다.

## 스테이지 (`CampaignRun.cs` · `CampaignStage`)

숲을 빠져나가는 길. 적은 전부 같은 외형이므로 이름을 **길목의 기사**로 통일하고, 장소 이름이 곧 스테이지 이름이다.

| 단계 | 현재 | 제안 |
|---:|---|---|
| 1 | 숲길 입구 | 유지 |
| 2 | 이끼 낀 오솔길 | 유지 |
| 3 | 안개 숲 | 안개 낀 골짜기 |
| 4 | 고목의 갈림길 | 유지 |
| 5 | 깊은 녹음 | 유지 |
| 6 | 숲의 경계 | 유지 |
| 7 | 마지막 고갯길 | 유지 |
| 8 | 숲의 끝 결투 | **숲의 끝** |

- 스테이지 적 이름: 신입생 → **길목의 기사**. 8단만 **숲 끝의 기사**로 둘 수 있다.
- 숲길 입구~숲의 끝이 이미 "빠져나가는 길"의 순서라서 이름 자체는 거의 손댈 것이 없다.

## 로비 명사와 안내 (`CampaignLobbyHud.cs` 등)

| 자리 | 현재 | 제안 |
|---|---|---|
| 탭 1 | 홈 | **거처** |
| 탭 2 | 스테이지 | **숲길** |
| 탭 3 | 편성 | 유지 |
| 탭 4 | 커리큘럼 | 유지 (사용자 결정 명칭) · 헤더 한 줄만 `떠돌이 기사의 가르침`으로 바꿀 수 있다 |
| 홈 안내 | 방을 나서기 전에 도전할 길과 기술 순서를 정하세요. | 거처를 나서기 전에, 갈 길과 검의 순서를 정하세요. |
| 홈 버튼 | 출정 | 유지 (또는 **길을 나선다**) |
| 스테이지 탭 제목 | 출정 지도 | **숲길 지도** |
| 스테이지 탭 안내 | 도전할 길을 고르고 오른쪽에서 상대와 커리큘럼 진행을 확인하세요. | 갈 길을 고르세요. 길목마다 기사가 결투를 청합니다. |
| 스테이지 탭 설명 | 기술을 정비하고, 숲길 너머의 상대에게 도전합니다. | 숲을 빠져나가는 길입니다. 길목의 기사를 꺾어야 다음 길이 열립니다. |
| 임무 배너 | 새 임무가 도착했습니다. | 떠돌이 기사가 가르칠 것이 있다고 합니다. |
| 임무 배너(잠김) | 스테이지 NN을 클리어하면 열립니다. | 숲길 NN을 지나면 가르쳐 준다고 합니다. |
| 스테이지 카드 | 임무 필요 | 가르침 필요 |
| 결과 창 서막 완료 | 서막의 임무를 모두 마쳤습니다. 이제 편성과 커리큘럼이 열립니다. | 숲에서 눈을 뜬 첫 결투들이 끝났습니다. 거처에서 편성과 커리큘럼이 열립니다. |
| 결과 창 | 여정을 계속하면 로비로 돌아갑니다. | 여정을 계속하면 거처로 돌아갑니다. |
| 결과 버튼 | 로비로 | 거처로 |
| 브리핑 버튼 | 로비로 [Esc] | 거처로 [Esc] |
| 결과 창 | 스테이지 NN 개방! | 숲길 NN 개방! |

'로비'·'스테이지'를 바꾸면 결과 창·배너·타이틀 요약·테스트 문자열까지 같이 바꿔야 한다. 범위가 크면 **탭 이름 둘(거처·숲길)과 홈·스테이지 탭의 안내 문장**만 먼저 바꿔도 느낌은 난다.

## 기술 · 커리큘럼

**바꾸지 않는다.** 19종 기술 이름(베기·찌르기·부수기·막기·흘리기·쳐내기·가로베기·사선베기·일도양단·호흡·급소 찌르기·유연함·준비·전진·투지·발검…)과 Q 정공·W 강공·E 기교, 참격·관통·수비 계열은 전부 떠돌이 기사가 가르치는 검술로 그대로 읽힌다. 설명 문구도 규칙 설명이라 세계관과 충돌하지 않는다.

- 예외: 적 전용 연습 기술 3종의 "훈련용 검으로" → "무딘 검으로" (위 참조).

## 코치 안내

코치의 목소리(누구인지)는 미정이므로 **지금의 시스템 목소리를 유지**한다. 나중에 떠돌이 기사의 말로 바꾸기로 정해지면 `MissionGuideBeat`의 제목·본문만 고치면 되고 구조는 그대로다.

## 텍스트가 아닌 권고

- **브리핑 배경**: 임무 2·5·8이 현대식 학교 교문(`LegacyDuel/Background/pa_background_-_school_in_game`)을 쓴다. 지금 서사에서는 학교에 들어가기 전이라 어긋난다. 새 그림이 생기기 전까지는 **숲(`ForestArena/forest-far`)으로 교체**를 권한다. 임무 1의 거처 배경은 맞는다.
- 로비 `스토리` 버튼이 여는 `Dialogue/dialogue.txt`("테스트/안녕/반갑다")는 구조 테스트 잔재다. 숨기거나 비워 두는 것이 낫다.
