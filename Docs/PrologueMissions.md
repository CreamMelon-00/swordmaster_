# 서막 임무

새 게임은 로비가 아니라 **서막** 임무 브리핑에서 시작한다. 스타크래프트 2 캠페인의 기함 탑승 전 임무(자유의 날개 '마 사라'까지)처럼, 짧은 임무가 한 줄로 이어지며 기본 규칙을 하나씩 가르친다. 분기와 선택지는 없다. 네 임무를 모두 마치면 지금의 방 로비(8스테이지·편성·상점·Q/W/E 3열)가 열린다. 이전의 '기초 연습' 튜토리얼은 삭제했고, 그 안내는 각 임무의 코치로 나눠 넣었다.

## 흐름

1. **브리핑**: 임무 배경 이미지, `서막 · 임무 N / 4`, 임무 제목, 목표, 등장하는 적(실루엣과 이름)을 보여 준다. 조작은 하단 가운데 **임무 시작** 버튼(또는 Enter) 하나다. 게임 안에 지도를 그리지는 않는다.
2. **시작 대사**: `Dialogue/mission-NN-intro`를 재생한다. 끝까지 넘기거나 Escape로 건너뛰면 전투가 시작된다.
3. **전투**: 코치 안내(`MissionCoachHud`)가 필요한 조작만 허용하고, 마지막 안내 뒤에는 자유 전투가 된다. Escape나 안내의 **임무 포기**를 누르면 브리핑으로 돌아간다(서막을 이미 마쳤다면 로비).
4. **종료 대사**: 승리했을 때만 `Dialogue/mission-NN-outro`를 재생한다. 패배하면 바로 결과로 간다.
5. **결과**: `임무 완료`/`임무 실패`. 승리하면 **재도전**(시작 대사 없이 같은 임무를 다시 한다)과 **다음 임무**, 실패하면 **브리핑으로**와 **재도전**이 있다. 마지막 임무를 이기면 **다음 임무**가 **여정 계속**이 되어 로비를 연다. 서막을 마친 뒤 다시 한 임무의 출구는 모두 로비로 간다.

대사 파일 8개에는 지금 `테스트` 한 줄만 들어 있다. 스토리는 나중에 이 파일에 쓴다(`DialogueAuthoring.md`). 파일이 없거나 형식이 틀리면 경고를 남기고 대사 없이 진행한다.

## 임무

| 임무 | 배우는 것 | 적 | 코치 순서 |
|---|---|---|---|
| 1 첫 타격 | 예약·확정·타격감 | 허수아비 학생 HP24/저항10, 공격하지 않음(숨고르기만) | 소개 → Q → Q → 확정 → 관찰 → 자유 |
| 2 맞서는 검 | 적 큐 확인, 공격 대결의 저항 피해, 붕괴 ×2, ACT 회복 | 신입생 36/12, 연습 베기·연습 내려치기 | 소개 → 적 확인(Tab) → Q(베기) → Q(예리한 베기) → 확정 → 관찰(첫 턴에 붕괴) → ACT → 자유 |
| 3 막아내기 | 방어, 기술열 회전, 타격 막기의 ACT 보상 | 신입생 40/15, 베기·내려치기·막기 | 소개 → Q(베기) → Q(막기) → 확정 → 관찰 → ACT → 자유 |
| 4 마지막 결투 | 제한 시간 | 선배 55/15, 기본 기술 | 소개 → 자유 |

- 플레이어는 HP100/저항50이고 **Q열 하나만** 쓴다. W/E 카드와 다음 칸은 화면에서 숨긴다.
- 편성·상점·스텝(A/D)·숨고르기는 서막 동안 잠겨 있다. 보상 재화와 스테이지 해금도 없다.
- 1~3 임무는 제한 시간이 없다. 4 임무는 코치 소개가 끝난 뒤부터 10초 제한이 흐른다.
- 1 임무의 적은 공격하지 않으므로 Q만 눌러도 두 턴 안에 이긴다. 초반 플레이 시간을 최소로 줄이기 위한 것이다.
- 적 이름·수치·문구는 모두 임시값이다.

## 코드

- Runtime `Prologue/PrologueMissions`: 네 임무의 정적 데이터(배경·목표·적·수치·Q열·코치 순서).
- Runtime `Prologue/PrologueMission`: 임무 하나. `CreateDuel`, `CreateGuide`, 대사 경로, 잠긴 기능 플래그.
- Runtime `Prologue/MissionGuide`: 코치 순서. 소개/예약/적 확인/확정/관찰/자유 단계마다 허용 입력을 정한다. 전투 판정은 바꾸지 않는다.
- Runtime `Prologue/PrologueRun`: 순서대로 이긴 임무만 진행한다. 이미 깬 임무를 다시 이겨도 진행은 바뀌지 않는다.
- Presentation `MissionBriefingHud`(정렬 250), `MissionCoachHud`(300). `LegacyCombatHud.SetMissionMode`는 임무 이름 표시, 제한 시간 표시 전환, 숨고르기 숨김을 맡는다.
- `DuelPrototypeController`: `StartNewGame`(Awake) → 브리핑, `StartMission` → 대사 → 전투. 대사가 끝나야 다음 단계로 넘어간다. 정리용 `CloseDialogue`는 다음 단계로 넘어가지 않는다. `RestartJourney`(로비의 여정 초기화)는 서막 진행을 유지하고 로비를 연다.

서막 진행은 디스크에 저장하지 않는다. Play를 다시 누르면 1 임무 브리핑부터 시작한다.
