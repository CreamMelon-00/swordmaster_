# 임시 세이브·로드

2026-09-30. 진행을 파일 하나에 자동 저장한다. 정식 세이브 시스템이 아니라 확인과 플레이 테스트가 끊기지 않게 하려는 임시 기능이다. 수동 슬롯은 없다.

## 타이틀 화면

Play를 누르면 타이틀이 먼저 나온다. 버튼은 두 개다.

- **이어하기** (Enter): 저장된 곳에서 다시 시작한다. 서막을 끝내지 않았으면 다음 임무의 브리핑, 끝냈으면 로비로 간다. 버튼 아래에 저장 요약(`서막 · 임무 2 / 4 · 맞서는 검` 또는 `로비 · 스테이지 클리어 3 / 8 · 재화 120`)이 나온다. 저장이 없거나 읽을 수 없으면 누를 수 없다.
- **새 게임**: 서막 1 임무부터 새로 시작하고, 곧바로 그 상태로 저장한다. 저장이 이미 있으면 확인 창이 먼저 뜬다(**새로 시작** 클릭 / **취소** 또는 Escape). 확인 창은 Enter로 넘길 수 없다.

저장 파일을 읽을 수 없거나 게임 규칙에 맞지 않으면, 타이틀에 경고를 띄우고 콘솔에 이유를 남긴다. 이어하기는 막히고, 새 게임을 고르면 그 파일을 덮어쓴다.

## 저장하는 것

| 항목 | 내용 |
|---|---|
| 서막 | 순서대로 깬 임무 수 |
| 재화 | 보유 재화 |
| 클리어 | 클리어한 스테이지 번호. 열린 스테이지는 여기서 다시 계산한다(첫 클리어가 다음 단계를 여는 규칙 그대로). |
| 보유 기술 | 기술 번호와 강화 단계, 얻은 순서대로. 상점 목록은 보유하지 않은 기술로 다시 만든다. |
| 편성 | **저장된** Q/W/E 편성(열마다 3개). 저장하지 않은 편집 중 상태는 저장하지 않는다. |

전투 중 상태는 저장하지 않는다. 전투 도중에 끄면 그 전투는 없던 일이 되고, 다시 켜면 브리핑이나 로비에서 시작한다.

## 저장 시점

설정이 확정된 순간에만 저장한다.

- 타이틀의 새 게임 직후
- 서막 임무를 처음 이겼을 때(종료 대사 전)
- 스테이지 결과가 확정됐을 때(보상 지급 직후)
- 상점 구매·강화
- 편성 저장
- 로비의 여정 초기화(서막 진행은 유지)

자동 저장은 타이틀에서 이어하기나 새 게임을 골랐을 때만 켜진다. 테스트나 코드에서 `StartNewGame`, `RestartJourney` 같은 API를 직접 부르면 파일을 건드리지 않는다.

## 파일

- 위치: `Application.persistentDataPath/save.txt`. Windows 에디터에서는 보통 `%USERPROFILE%\AppData\LocalLow\<회사>\<제품>\save.txt`다.
- Unity 메뉴 **Turn Limbo > 세이브 삭제**로 지우고, **Turn Limbo > 세이브 폴더 열기**로 위치를 연다.
- 임시 파일(`save.txt.tmp`)에 먼저 쓴 뒤 교체한다(이전 저장은 교체가 끝날 때까지 `save.txt.bak`로 둔다). 쓰는 도중 꺼지거나 교체가 실패해 `save.txt`가 없으면, 남은 `.tmp`나 `.bak` 중 읽을 수 있는 것을 불러온다.
- 사람이 읽을 수 있는 줄 단위 텍스트다. 첫 줄은 `turn-limbo-save 1`(형식 버전)이다. 다른 버전, 모르는 항목, 빠지거나 두 번 나온 항목은 거부한다.

```
turn-limbo-save 1
prologue 4
currency 120
cleared 1 2
skill 1 1
...
lane 0 1 2 7
lane 1 3 4 8
lane 2 5 6 9
```

## 코드

- Runtime `Campaign/CampaignSave`, `CampaignRun.CaptureSave`/`TryRestore`: 캠페인의 저장 상태와 규칙 검사. 모르는 기술, 중복, 강화 범위, 시작 기술 누락, 열 개수·열 배정 위반이면 아무것도 바꾸지 않고 거부한다.
- Runtime `Prologue/PrologueRun.TryRestore`: 0~4 범위만 받는다.
- Runtime `Save/GameSave`: 서막과 캠페인을 묶는다. 두 쪽을 모두 검사한 뒤에 적용한다. `Validate`는 새 인스턴스에 적용해 보는 검사다.
- Runtime `Save/GameSaveCodec`: 텍스트 형식.
- Presentation `GameSaveStore`: 파일 읽기·쓰기·삭제. `TitleHud`: 타이틀 화면.
- `DuelPrototypeController`: `ShowTitle`(Awake), `ContinueGame`, `NewGameFromTitle`, 저장 시점마다 `AutoSave`. 테스트는 `SaveStore`를 임시 경로로 바꿔 쓴다.

저장 형식을 바꾸면 `GameSave.CurrentVersion`을 올린다. 지금은 이전 버전을 변환하지 않으므로, 버전을 올리면 기존 저장은 이어할 수 없다.
