# 스테이지 5: 1대3 전투

스테이지 5는 엘리사 한 명이 수련생 세 명을 상대한다. 기존 스테이지 해금과 첫 클리어 보상 **연마(ID 46)** 는 유지한다. 다른 스테이지, 이야기 임무, 수련, 로컬·온라인 대전은 기존 1대1 규칙을 유지한다.

## 첫 임시 밸런스

| 항목 | 각 수련생 |
| --- | --- |
| 체력 | 50 (세 명 합계 150) |
| 저항 | 10 |
| 기술 위력 | 원본 기본 위력의 70%, 소수점 버림, 최소 1 |
| 기존 스테이지 위력 보너스 | 적용하지 않음 |
| 추가 반격 | 없음 |
| 턴마다 예약하는 기술 수 | 2 → 1 → 2 반복 |

세 명이 살아 있으면 공유 적 대기열은 6 → 3 → 6개가 된다. 수련생마다 공격과 방어의 구성이 조금 다르다. 각자의 기술 순서를 유지하며 턴마다 시드로 인물 순서를 섞고 교차 배치한다. 같은 인물만 연속해서 행동하는 상황을 줄이면서 바톤을 넘기는 흐름을 만든다. 사망한 수련생은 이후 턴 대기열을 만들지 않는다.

## 대상과 취소

- 같은 순번의 적 기술 소유자가 엘리사의 자동 대응 대상이다.
- 적 행동이 없거나 취소된 순번에서는 직전 상대를 계속 공격한다. 직전 상대가 사망했다면 생존한 적이 대신한다.
- 체력·저항·버프·반격 잔여 횟수는 각 인물이 따로 소유한다. 대기 중인 적에게 현재 상대의 피해나 효과가 전달되지 않는다.
- 적 붕괴는 **그 적의 이후 예약만 취소**한다. 현재 기술은 남은 다중 타격까지 마친다. 다른 적의 예약은 계속 실행한다.
- 사망 시 현재 기술의 후속 타격은 멈추고, 그 적의 이후 예약을 취소한다. 같은 타격 시점의 양측 행동을 먼저 계산하는 기존 규칙은 유지한다.
- 엘리사가 붕괴하면 기존대로 엘리사의 이후 예약을 모두 취소한다. 취소는 ACT를 돌려주지 않는다.
- 취소된 예약은 실행 사본에서만 비운다. 공개 대기열의 카드와 원래 소유자 번호는 남겨 UI 파괴 연출에 사용한다. 순번을 앞당기지 않는다.
- 모든 적의 체력이 0이 되어야 승리한다. 엘리사가 같은 시점에 사망하면 기존처럼 패배를 우선한다.

## 연결 구조

`LegacyQueuedDuel`의 기존 API와 전투 판정을 확장했다. `Enemy`는 현재 상대를 계속 가리키므로 기존 타격·조건·맞물림·회피·압박·순환·숙련 처리가 같은 슬롯에 적용된다. `BeginNextSlot`이 상대를 선택하고, `CompleteCurrentSlot` 이후에도 선택을 유지해 마지막 피격·사망 연출이 다른 인물에게 옮겨가지 않게 한다.

선택적인 `ILegacyEnemyRosterView`가 개별 적 상태, 이름, 현재 상대, 카드 소유자, 실제 대응 대상, 취소 여부, 적 전체 체력을 제공한다. 기존 `ILegacyDuelView`와 대전 프로토콜은 바꾸지 않는다. 1대1 `LegacyQueuedDuel`도 적 한 명을 가진 명부로 조회할 수 있다.

편성 예상은 모든 적의 체력·저항·버프·반격·취소 상태와 대기열 소유자를 복사해 평균 위력으로 같은 규칙을 실행한다. 예상 조회가 본 전투의 적 상태나 난수에 영향을 주지 않는다. 대기열 순서 생성은 위력 주사위와 별도 난수를 사용한다.

## 화면과 교대

현재 교대 전용 속도는 **1.35배**다. `DuelPresentationSettings`의 `Enemy Handoff Speed Multiplier`(1~2)로 조절하며, 다음 적의 선행 접근과 실제 진입·이전 적의 퇴장에 적용한다. 선행 접근과 진입은 자신의 현재 Y에서 가로 거리만 좁히고, 퇴장의 옆 디딤에는 X/Y 속도·가감속을 함께 높인다. 플레이어 높이에 맞추는 이동과 정렬 대기는 사용하지 않는다. 바로 다음 순번의 실제 상대가 바뀔 때만 기술 사이 대기도 같은 배율로 줄인다. 빈칸/취소 칸에서 직전 상대를 계속 공격하거나 같은 상대가 연속 행동할 때는 줄이지 않는다. 공격 동작과 0.7배로 조절한 기본 템포, 준비의 동시 접근은 그대로 사용한다.

준비 중에는 살아 있는 세 적이 같은 프레임에 함께 다가온다. 속도는 기본 접근 속도에 첫 번째 적 0.8배·두 번째 적 1배·세 번째 적 1.2배를 곱한다. `DuelPresentationSettings`의 `Enemy Planning Speed Factors` X/Y/Z에서 각각 조절한다(범위 0.1~2). 엘리사도 가장 가까운 적을 기준으로 접근하며 각 적은 최소 간격에서 멈춘다. 너무 붙어서 준비가 시작되면 모두 안전 간격을 확보한 뒤 다가간다. 편성의 Tab·설명·넘기기 시계와 일시정지는 기존대로 따른다. 준비 중 임의의 Y 왕복은 추가하지 않는다.

현재 기술의 마지막 실제 타격이 끝나면, 다음에 행동할 살아 있는 적이 회복 동작과 칸 사이 간격 동안 미리 접근한다. 자신의 실제 높이에서 가로 간격 5.2를 확보하고, 도착하면 해당 기술의 첫 준비 그림을 유지한다. 플레이어와 같은 높이나 지정한 옆 진입선을 찾아 이동하지 않는다. 다음 칸이 시작되어야 실제 상대와 기술이 바뀐다. 같은 적의 연속 행동이면 다른 적을 먼저 부르지 않으며, 죽거나 취소된 소유자의 예약은 건너뛴다. 다중 타격의 중간에는 선행 접근을 시작하지 않는다. 준비 의도는 기술 판정·피해·경험치·대기열을 진행시키지 않으며 턴 전환·사망·초기화·컷신에서 정리한다.

세 적은 서로 다른 기존 학생 외형으로 전장에 함께 서 있다. 기술 소유자가 바뀌면 새 적이 자신의 현재 위치에서 엘리사에게 다가오며, 엘리사는 짧게 발을 디뎌 기다린다. 이전 적은 새 접근선에서 짧게 뒤·옆으로 공간을 비우고 멈춘다. 피격 뒤 추격은 기존대로 진행하며, 교대 때 몸체를 다른 위치로 순간 이동시키지 않는다. 엘리사가 대기 적의 X 위치를 지나친 경우에도 실제 안전 걸음으로 전후 관계를 복구한다.

실제 발 Y로 네 인물의 몸·그림자·부착 효과를 함께 정렬하고, 발밑 원은 각자의 실제 위치를 따른다. 카메라는 준비 중 살아 있는 적 모두를 화면에 담고, 기술 실행 중에는 현재 교전하는 두 인물 쪽으로 구도를 좁힌다. 칸 사이에는 전체 구도로 강조를 풀며 다음 상대를 향해 이동한다. 개별 사망은 짧게 흐려진 뒤 숨겨지며 마지막 적이 쓰러져야 전투 종료 연출로 넘어간다. 재도전은 같은 몸체를 재사용해 복원하고 1대1 전투로 돌아가면 추가 적을 정리한다.

적 머리 위에 번호와 개별 HP·저항이 있는 작은 패널을 배치하고, 공유 대기열 카드에도 같은 번호·색을 표시한다. 패널들은 서로 겹치거나 다른 인물의 머리를 덮지 않는 가까운 위치를 찾는다. 현재 교전 상대와 Tab으로 확인 중인 상대를 강조한다. 소유자별 취소는 해당 카드만 파괴하며 빈 순번을 유지하므로 엘리사의 같은 순번 기술이 다른 칸으로 잘못 대응하지 않는다. 시작 카드에는 ‘훈련생 3인조’를, 스테이지 미리보기에는 세 명의 개별 수치와 공유 대기열을 표시한다.

## 검증 범위

`TrioBattleTests`는 공유 순서 재현, 개별 피해 대상, 현재 상대 유지, 소유자별 붕괴 취소, 다중 타격 중 사망, 전원 사망 승리, 사망자의 다음 턴 제외, 빈 슬롯 대상 유지, 예상과 실제 결과 일치, 기존 1대1 조회, 스테이지 수치·행동 수·보상을 검증한다. 실제 실행 결과는 `Docs/Validation.md`에 기록한다.

`EnemyRosterArenaPlayModeTests`는 실제 몸체·정렬·원·교대 접근·음수 간격 복구·개별 붕괴/사망·컷신·반복 초기화를, `EnemyRosterHudPlayModeTests`는 개별 패널·대기열 소유자·취소된 칸의 대응·세 화면 비율의 실제 렌더링을 확인한다. `TrioBattleFlowPlayModeTests`는 실제 스테이지 5 진입부터 세 적의 행동, 일시정지, 개별 사망과 마지막 승리, 보상·재도전·1대1 복귀까지 연결한다.

`EnemyEnsembleMotionPlayModeTests`는 세 적 동시 준비 이동·개별 속도·시계·근접 분리·준비 그림·교대 위치 연속·수명 정리와 렌더링을 확인한다. `EnemyEnsembleFlowPlayModeTests`는 실제 스테이지 5에서 마지막 타격 뒤 선행 접근, 판정 대상과 피해 유지, 다중 타격 대기, 사망자의 취소 예약 건너뛰기와 일시정지를 확인한다.
