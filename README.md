# Turn Limbo Next

`Turn_Limbo`의 전투 아이디어와 검증된 리소스를 계승하되, 런타임 구조는 새로 만드는 프로젝트다.

## 현재 목표

- Unity 6 Universal 2D 기반의 깨끗한 프로젝트 유지
- Unity에 의존하지 않는 전투 규칙과 테스트 구축
- 작은 EditMode 테스트로 규칙을 먼저 고정
- 원본 전투에 필요한 리소스를 선별 이식
- 기존 큐 전투와 정비·성장이 연결된 8스테이지 루프 구축

## 현재 범위

일반 기술 4종(준비·전진·투지·발검)을 추가해 상점은 총 10종을 판매한다. 다음 행동 지원, 위험을 감수한 ACT 확보, 저항력 회복, 상대 방어 대응을 실제 판정·편성·설명에 연결했다. 체인 기술은 이번 리뉴얼 범위에서 제외한다. 정확한 조건·시점·원본과의 차이는 `Docs/ImportedNonChainSkills.md`를 따른다.

기술을 길게 확인하면 조건에 맞는 적 기술을 밝은 청록색으로 표시하고, 다음 예약 칸의 성립은 이중 테두리와 큰 표식으로 강조한다. 실제 효과 발동은 금색으로 구분한다. 양쪽 상태창에 현재 적용 중인 위력/피해 감소와 새로 받은 다음 칸 버프의 수치·지속을 표시하며, 적용된 버프는 카드 주위의 은은한 입자로 표시한다. 상점 강화만으로 입자를 표시하지 않는다. 조건·수명·키 해제 동작은 `Docs/SkillConditionFeedback.md`를 따른다.

스킬 상세는 공통 `SkillInfoView`의 ACT/위력·방어/타격 타일, 의미별 색의 각인 기호와 키워드 배지, 짧은 조건·시점 설명으로 표시한다. 상점·편성·키 홀드/적 확인 팝업의 읽는 순서를 맞췄으며 긴 설명 문단과 반복 수치 문장은 줄였다. 편성 선택판에 강화 단계를 유지하고, 공통 피해 규칙은 개별 설명에서 제외한다. 실제 판정과 정보 구성은 `Docs/SkillInformationDesign.md`를 따른다.

홈·스테이지·편성·상점은 팝업이 아닌 헤더 아래 전체 화면을 사용한다. 홈은 방과 준비 메뉴, 스테이지는 카드 목록과 오른쪽 출정 정보로 구성한다. 상단 메뉴는 고정하고 페이지만 실제 시간 0.22초 동안 페이드/32px 이동으로 전환한다. 화면을 오가도 편성 초안·선택한 기술·상점 스크롤을 유지한다. 별도 씬이나 Inspector 연결 없이 Play를 다시 시작하면 적용된다.

최신 비주얼은 약한 스팀펑크의19세기 검술 클럽이다. 가스등/황동 배관이 있는 준비실과 숲길, 구리·강철·황동·올리브 법랑의15개 검 배지, 목재/가죽 UI와 종이·잉크 선택 상세를 사용한다. 로비부터 전투·결과·튜토리얼까지 `DuelVisualTheme` 팔레트와 비차단 황동 테두리를 공유한다. 캐릭터/연출/조작은 유지했다. 최신 제작 프롬프트·자산 경로·원본 보존·표현 한계는 `Docs/Art/VictorianDuelTheme.md`를 따른다. 아래의 청록 중립 HUD/이전 아이콘 그림 설명은 제작 경과다.

현재 진입점은 방 로비다. 출정·스킬 편성·상점을 오가고, 열린8개 스테이지에서 골라 입장한다. Q/W/E 각 열 3개씩 편성하며 카드 클릭은 설명만 선택하고, 같은 열의 카드 드래그로만 교체·순서를 바꾼다. 상점은 구매/강화 목록을 나누고 선택한 기술의 상세와 거래 버튼 한 곳에 정보를 모은다. 선택한 기술만 상세 설명을 표시한다. 빈칸이 있으면 저장할 수 없으며, 미저장 변경은 저장하거나 되돌린 뒤 출정한다. 구매한 기술은 자동 투입되지 않는다. 승리/패배 후에는 전장 위 결과 창에서 보상과 해금을 확인하고 로비/재도전/다음 스테이지를 직접 선택한다. 전투 중 Escape는 보상 없이 로비 복귀, 결과 창 Enter/Escape는 로비 복귀, 로비 Escape는 홈, 스테이지 탭 Enter는 선택한 단계 출정이다. 홈/스테이지의 기초 연습으로 보상·여정에 영향을 주지 않는 튜토리얼에 입장한다. 예약·회전·방어·적 확인·확정·교전·ACT 회복을 직접 조작하며 배우고 자유 전투로 마무리한다. 연습은 시간 제한이 없다. 사용법은 `Docs/BattleResultsAndTutorial.md`, 최신 편성/상점 설명은 `Docs/LobbyAndLoadout.md`를 따른다.

최신 기술 아이콘15개는 검만 사용한다. ACT 회복·후속 위력·피해 감소·고화력·연타·변동 한방을 문양/표식과 역할 텍스트로 구분하고 구매 기술의 미이식 효과는 표시하지 않는다. 저항 피해는 특정 속성의 전용 기능이 아니라 모든 공격이 상대 공격과 맞붙을 때의 공통 규칙이다. 실제 의미는 `Docs/SkillRoleLanguage.md`, 생성 프롬프트/파일은 `Docs/Art/SwordSkillIcons.md`를 따른다. 아래9개 키캡과 그림 공유 설명은 이전 구현 기록이다.

로비에서 출정하면 편성한 기술로 선택한 상대와 한 판을 진행한다. 10초 동안 Q/W/E 기술열의 선두 기술을 큐에 예약하고, 턴을 확정하면 양쪽 큐의 같은 순번끼리 차례로 충돌한다. 기술 선택만으로 공격하거나 피해를 주지 않는다.

원본의 ACT 소비·이월, 기술열 회전, 적 행동 예고, 랜덤 위력, 다중 타격, 체력·저항력·붕괴와 기본 기술 효과를 옮겼다. 다중 타격은 슬롯을 시작할 때 위력을 한 번 정하고, 원본 공격 클립의 타격 시점마다 피해를 나누어 반영한다. 슬롯의 마지막 동작이 끝난 뒤 승패를 확인하며, 동시 사망은 원본처럼 플레이어 패배를 우선한다.

화면은 월드 공간의 `SpriteRenderer` 전장과 uGUI HUD로 구성한다. 원본 플레이어·신입생 스프라이트, 12fps 애니메이션 클립, 그림자, 충돌 파티클, 한글 폰트와 효과음을 사용한다. 배경은 앞뒤 폭이 있는 2.5D 벨트스크롤 녹빛 숲길의 안개·원경 나무·중경·근경의4층으로 바꾸고 서로 다른 속도로 좌우 반복한다. 지면을 살짝 위에서 내려다보는 구도이며, 캐릭터는 넓은 바닥 안쪽에 선다. 중경·근경은 첫 숲 배경의 70% 크기로, 원경 안개와 나무의 기본 크기는 첫 배경의80%이며 각각 따로 튜닝한다. 중경의 흙·이끼와 나무 윤곽은 더 선명하고 단순한 픽셀 아트로 정리했다. 캐릭터 크기와 카메라 확대값은 바꾸지 않았다. 원본 교문 PNG는 보존한다. HUD 장식은 배경 독립적인 중립색 패널로 바꾸고, 기존 위치 역할과 조작 흐름을 유지하면서 하단 공간을 줄였다. ACT 숫자와 10칸 게이지는 같은 값을 표시하며, 기술 아이콘은 같은 키캡 외곽을 공유하는 새 버튼 세트 9개로 교체했다. 현재/다음/큐/기록의 매핑과 ACT 비용은 그대로이며, 원본 퍼즐 PNG는 보존한다. 첫 접근과 재접근은 빠르게 하고, 받은 체력·저항 피해에 따라 밀림을 크게 표현하며 방어 시 감소시킨다. 공격자는 밀린 상대를 빠르게 추격한다. 턴이 끝나도 원위치로 복귀하지 않고 그 지점에서 다음 편성을 이어가며 카메라와 머리 위 HUD가 따라간다. 재대결만 처음 위치로 초기화한다. 필요한 표현 요소를 새 구성으로 연결한 한 판이며, 원본 씬 전체를 이식한 것은 아니다.

승리하면 재화를 받고 정비 화면에서 새 기술 10종을 획득하거나 소유 기술을 최대 +3까지 강화한 뒤 다음 스테이지로 진행한다. 같은 적 리소스·행동 패턴을 활용한 수치 변형 8단계이며, 다음 전투에 체력과 저항을 회복한다. 패배 후 재도전은 재화·획득·강화를 유지한다. 진행은 Play 세션 안에서만 보관하고 종료 후 이어하기는 아직 없다. 자세한 가격·스테이지 수치·기존 구매 6종의 미이식 기술 효과는 `Docs/CampaignLoop.md`를, 신규 4종은 `Docs/ImportedNonChainSkills.md`를 따른다.

체인 기술, 덱 편집과 시나리오는 아직 포함하지 않는다. 일반 전투에 A 회피·D 압박을 추가했다. 플레이어 몸의 흰 원이 줄어드는 성공 구간에 맞추며 왼쪽은 A, 오른쪽은 D다. 성공 시 더 큰 이동·잔상, 짧은 슬로모션·카메라 집중·배경 암전을 주고 강도는 연출 설정에서 조절한다. 연타에는 기술 전체에 적용한다. 공격 압박은 위력만큼 추가 체력 피해, 내 방어 압박은 받는 피해 절반이다. 시도하면 다음 턴 기본 ACT 3 회복만 빠진다. 기존 기초 연습에는 스텝을 넣지 않았으며 자세한 계약은 `Docs/StepPrototype.md`를 따른다. 원본 신규 소유/로그라이크 시작 구성인 기본 9개를 배치한다. 현재 벨트스크롤 배경의 파일·배치·제작 프롬프트는 `Docs/Art/PixelBeltForest.md`에, 초기 벨트 구성은 `Docs/Art/BeltForest.md`, 첫 숲 제작 기록은 `Docs/Art/ForestLayers.md`에 기록한다.

반격 시스템을 추가했습니다. 내 칸이 비어 있고 상대가 공격하면 그 칸을 반격기가 채워 맞붙습니다. 방어형은 피해를 줄이고, 공격형은 합이 됩니다. 반격은 턴당 횟수가 정해져 있고 ACT·열 회전 없이 계획 단계에서 예고됩니다. 플레이어 반격은 그 칸에서 회피를 시도하면 나가지 않습니다. 현재는 임시로 5~6스테이지 적이 막기, 7~8스테이지 적이 강력한 부수기를 턴당 1회 씁니다. 자세한 규칙은 `Docs/CounterSystem.md`를 따릅니다.

기술의 수치·시작 효과·역할·설명 문구를 정의 표 하나(`LegacySkillDefinitions`)로 모았습니다. 새 기술은 표에 한 항목을 추가하면 전투·조건 미리보기·상점·상세 카드에 함께 반영됩니다. 구조와 아직 표현할 수 없는 효과는 `Docs/SkillDefinitions.md`를 따릅니다.

배경 크기/세로 위치, 공격 프레임 배율/연타·스킬 간격/히트 스톱, 타격 발광/Bloom은 저장 가능한 `DuelPresentationSettings` 자산에서 조절한다. 상단 `Turn Limbo → 연출 튜닝 열기`로 선택하고 Play 중 화면을 보면서 튜닝할 수 있다. 기본은 원본 공격 동작을 유지하며 연타 사이0.1초·스킬 사이0.28초를 쉬고 타격 직후 실제0.04초를 멈춘다. 기존 HDR 불꽃에 짧은 발광과 Bloom을 더했으며 강도/크기/수명/섬광을 끌 수 있다. 자세한 항목과 저장 방법은 `Docs/PresentationTuning.md`를 따른다.

## 실행 방법

1. Unity에서 프로젝트를 연 뒤 아무 씬에서나 Play를 누른다. 처음이면 홈의 `기초 연습 · 튜토리얼`, 일반 전투는 출정→스테이지 선택→도전으로 입장한다.
2. `Q/W/E`를 짧게 눌렀다 놓으면 해당 기술열의 선두 기술을 큐에 추가한다. ACT를 소비하고 선두 기술은 뒤로 회전한다. 화면 버튼 또는 `1/2/3`도 사용할 수 있다.
3. `Space` 또는 Enter로 턴을 확정한다. 10초가 지나도 자동 확정한다. ACT가 0이 되어도 즉시 실행하지 않는다.
4. `Q/W/E`를 1초 이상 누르면 기술 설명을 본다. `Tab`을 누르는 동안 적 기술을 좌우 화살표로 확인하며 편성 시간이 느려진다. 전투 중 `Shift`는 충돌 재생을 느리게 한다. 플레이어 몸 주변 원의 왼쪽 A 회피/오른쪽 D 압박을 고정 성공 구간에 맞춘다.
5. 결과 창에서 `로비로`/Enter/Escape로 돌아오거나 `재도전`/개방된 `다음 스테이지`를 누른다. 로비 상점에서 기술을 획득·강화하고 편성 탭에서 장착한다. 튜토리얼은 실제 조작에 맞춰 안내가 진행되며 자동 확정하지 않는다. 로비의 `여정 초기화`는 확인 후 진행을 초기화한다.

왼쪽 하단의 책 아이콘 또는 `L`은 편성 중 기술과 피해 기록을 열고 닫는다. 오른쪽 체크 아이콘 또는 `Space`/Enter는 큐 전체를 확정한다. 각 아이콘 아래에 입력 키를 표시한다. 기록을 확인하는 동안에도 원본처럼 편성 타이머는 계속 흐른다.

Game 창은 전장의 원본 구도가 맞는 16:9 비율을 권장한다. 각 캐릭터 머리 위에 스킬 큐를 위쪽, 체력·저항을 그 아래에 묶어 배치한다. 둘 다 캐릭터와 Tab 확대를 함께 따라가되 표시 크기는 카메라 확대에 따라 커지지 않는다. 긴 큐는 최대 5칸마다 줄바꿈하며 묶음 전체를 화면 안으로 제한한다. 설명 패널도 기존 화면 경계 제한을 유지한다. 이는 다른 비율에서 전장 카메라 구도까지 재설계했다는 의미는 아니다.

플레이어는 HP 100 / 저항력 50, 신입생은 HP 80 / 저항력 15로 시작한다. ACT는 첫 턴 3, 이후 기본 +3과 기술 보상 및 잔여분을 합산해 최대 10이다. 적은 원본 기술 1–6을 순환하고 턴당 행동 개수도 원본의 `2 → 3 → 2 → 1`이다.

전투 판정은 Unity에 의존하지 않는 `LegacyQueuedDuel`이 소유한다. 화면·입력·애니메이션·파티클은 컨트롤러의 수동 시계를 따르며, Tab 검사와 Shift/치명타 슬로모션은 편성·재생 속도를 조절한다. 현재 구조는 `Docs/Architecture.md`, 전장 리소스는 `Docs/LegacyPresentationAssets.md`, 현재 HUD는 `Docs/CompactHudDesign.md`, 예전 HUD의 원본 대응은 `Docs/LegacyHudParity.md`, 실제 검증 결과는 `Docs/Validation.md`에서 확인한다.
